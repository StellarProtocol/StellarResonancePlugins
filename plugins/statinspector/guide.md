# StatInspector

Your live character attributes on screen — a compact mini-HUD with exactly the stats you
care about.

![Stat inspector](https://cdn.revette.io/plugins/statinspector/media/stat-inspector.png)

## How to use

1. Install the plugin and launch the game **Modded**.
2. Open the StatInspector window from the Stellar overlay to pick your stats: the grouped
   settings picker lists every attribute — tick the ones you want on the mini-HUD.
3. Drag the mini-HUD anywhere. Its position and shown/hidden state are remembered across
   relaunches.

## Tips

- Values update live, so it's handy for checking how a gear or module swap actually moves
  your numbers.
