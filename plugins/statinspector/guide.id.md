# StatInspector

Atribut karaktermu secara langsung di layar — mini-HUD ringkas dengan persis statistik yang kamu pedulikan.

![Tampilan statistik](media/stat-inspector.png)

## Cara pakai

1. Pasang plugin lalu jalankan game dalam mode **Dengan mod**.
2. Buka jendela StatInspector dari overlay Stellar untuk memilih statistikmu: pemilih pengaturan berkelompok menampilkan setiap atribut — centang yang ingin kamu tampilkan di mini-HUD.

![Pemilih statistik](media/statinspector-settings.png)
3. Seret mini-HUD ke mana saja. Posisi dan status tampil/sembunyi-nya diingat lintas peluncuran ulang.

## Tips

- Nilainya diperbarui secara langsung, jadi berguna untuk memeriksa bagaimana pertukaran gear atau modul benar-benar mengubah angkamu.
