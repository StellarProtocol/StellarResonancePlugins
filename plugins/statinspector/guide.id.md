# StatInspector

Atribut karaktermu secara langsung di layar — mini-HUD ringkas dengan persis statistik yang kamu pedulikan, dalam urutan yang kamu mau.

![Tampilan statistik](media/stat-inspector.png)

## Cara pakai

1. Pasang plugin lalu jalankan game dalam mode **Dengan mod**.
2. Buka StatInspector dari overlay Stellar, atau klik ikon roda gigi di mini-HUD. Di **Semua statistik**, klik sebuah statistik untuk menambahkannya ke mini-HUD (klik lagi untuk menghapusnya). Gunakan kotak pencarian untuk menemukannya dengan cepat.

![Pemilih statistik](media/statinspector-settings.png)
3. Buka **Di HUD** untuk melihat pilihanmu sesuai urutan tampil di mini-HUD. Seret sebuah baris untuk memindahkannya, atau klik ✕ untuk menghapusnya.

![Urutan statistik](media/statinspector-order.png)
4. Di bagian **HUD**, pilih jumlah **Kolom** mini-HUD, dan naikkan penggeser **Latar** jika angkanya sulit dibaca di atas tampilan game.
5. Pindahkan mini-HUD di editor tata letak HUD. Di sana mini-HUD tampil dalam ukuran sebenarnya, dengan statistik contoh jika kamu belum memilih apa pun. Posisi dan status tampil/sembunyi-nya diingat lintas peluncuran ulang.

## Tips

- Nilainya diperbarui secara langsung, jadi berguna untuk memeriksa bagaimana pertukaran gear atau modul benar-benar mengubah angkamu.
- **Hapus semua** akan bertanya sekali lagi sebelum menghapus semua statistik dari mini-HUD.
- Tombol **?** menjelaskan setiap pengaturan.
