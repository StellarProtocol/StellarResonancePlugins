# StatInspector

Ang live na attribute ng character mo sa screen — compact na mini-HUD na may eksaktong mga stat na mahalaga sa iyo, sa pagkakasunod na gusto mo.

![Pagtingin ng stats](media/stat-inspector.png)

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa **May mod**.
2. Buksan ang StatInspector mula sa overlay ng Stellar, o i-click ang gear sa mini-HUD. Sa **Lahat ng stat**, i-click ang isang stat para idagdag ito sa mini-HUD (i-click ulit para alisin). Gamitin ang search box para mabilis itong mahanap.

![Pagpili ng stats](media/statinspector-settings.png)
3. Buksan ang **Nasa HUD** para makita ang mga napili mo ayon sa pagkakasunod sa mini-HUD. I-drag ang isang row para ilipat ito, o i-click ang ✕ para alisin.

![Pagkakasunod ng stats](media/statinspector-order.png)
4. Sa seksyong **HUD**, piliin kung ilang **Column** ang gagamitin ng mini-HUD, at taasan ang slider ng **Likuran** kung mahirap basahin ang mga numero sa ibabaw ng laro.
5. Ilipat ang mini-HUD sa HUD layout editor. Doon, nakikita ito sa tunay na laki, may halimbawang stats kung wala ka pang napipili. Natatandaan ang posisyon at shown/hidden na estado nito kahit mag-relaunch ka.

## Mga Tip

- Live na nag-a-update ang mga value, kaya kapaki-pakinabang ito para tingnan kung paano talaga naaapektuhan ng pagpalit ng gear o module ang mga numero mo.
- Magtatanong muna ang **Burahin lahat** bago nito alisin ang lahat ng stat sa mini-HUD.
- Ipinapaliwanag ng mga button na **?** ang bawat setting.
