# Auto Gather

Automatically harvests life-resource nodes — herbs, ore, wood, gems and more. Pick a resource type and
Auto-Gather walks to and gathers every node of that type nearby, so you can farm hands-free.

## How to use

1. Install the plugin and launch the game **Modded**.
2. Stand near the resources you want to farm and open the **Auto-Gather** window from the Stellar overlay.
   The line under the title shows what it's doing, e.g. **Ready · *resource* · 5 nearby**.
3. Under **Resource**, click the type you want to gather. Each row shows how many are nearby (×5) and how far away the closest one is.
4. Under **Gather mode**, pick **Normal** or **Focus** (Focus gives rarer loot).
5. Press **Start**. Auto-Gather walks to each node of that type and harvests it, then moves to the next. Press **Stop** any time.

It walks around obstacles on its own; if no node of the chosen type can be reached right now, the status line says so and it tries again shortly.

## Options

- **Focus** — spends Focus for rarer loot. Gathering stops when you run out of Focus. **Normal** doesn't use Focus.
- **Focus limit** — in Focus mode, gathering stops once this much Focus has been spent since you pressed Start. Drag it all the way right for **No limit**.
- **Auto-close reward popups** (**On** / **Off**) — closes the daily reward popup so a long session isn't interrupted.

Every setting has a **?** button that explains it. Auto-Gather only runs while you're in the world, alive, and out of combat.
