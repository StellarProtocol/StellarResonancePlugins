# Auto Gather

Automatically harvests life-resource nodes — herbs, ore, wood, gems and more. Pick a resource type and
Auto-Gather walks to and gathers every node of that type nearby, so you can farm hands-free.

## How to use

1. Install the plugin and launch the game **Modded**.
2. Stand near the resources you want to farm and open the **Auto-Gather** window from the Stellar overlay.
3. The **Nearby Resource Types** list fills in on its own. Click the type you want — a ▶ marks the locked type.
4. Press **Start**. Auto-Gather walks to each node of that type and harvests it, then moves to the next. Press **Stop** any time.

## Options

- **Focus mode** — spends Focus for the rarer, higher-value gather. It's strict: when you run out of Focus it stops automatically rather than switching to a normal gather.
- **Auto-close reward popups** — dismisses the daily reward popup so a long unattended session isn't interrupted.

Auto-Gather only runs while you're in the world, alive, and out of combat.
