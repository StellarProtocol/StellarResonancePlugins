# Awtomatikong Pag-ani

Awtomatikong inaani ang mga life-resource node — halamang-gamot, mineral, kahoy, hiyas, at iba pa. Pumili ng uri ng resource at ang Awtomatikong Pag-ani ay lalakad papunta at mag-aani ng bawat node ng uring iyon na malapit, kaya puwede kang mag-farm nang walang kamay.

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa **May mod**.
2. Tumayo malapit sa mga resource na gusto mong i-farm at buksan ang window ng **Awtomatikong Pag-ani** mula sa overlay ng Stellar.
   Ipinapakita ng linya sa ilalim ng pamagat ang ginagawa nito, halimbawa **Handa · *resource* · 5 sa malapit**.
3. Sa **Resource**, i-click ang uring gusto mong anihin. Ipinapakita ng bawat row kung ilan ang malapit (×5) at gaano kalayo ang pinakamalapit.
4. Sa **Paraan ng pag-ani**, piliin ang **Normal** o **Focus** (mas bihirang loot sa Focus).
5. Pindutin ang **Simulan**. Ang Awtomatikong Pag-ani ay lalakad sa bawat node ng uring iyon at aanihin ito, pagkatapos ay lilipat sa susunod. Pindutin ang **Ihinto** anumang oras.

Kusa itong umiikot sa mga harang; kapag walang maabot na node ng napiling uri sa ngayon, sinasabi ito ng status line at susubukan ulit maya-maya.

## Mga opsyon

- **Focus** — gumagastos ng Focus para sa mas bihirang loot. Humihinto ang pag-ani kapag naubos ang Focus. Hindi gumagamit ng Focus ang **Normal**.
- **Limit ng Focus** — sa Focus mode, humihinto ang pag-ani kapag nagamit na ang ganitong dami ng Focus mula nang pindutin mo ang Simulan. I-drag hanggang dulo sa kanan para sa **Walang limit**.
- **Isara agad ang popup ng gantimpala** (**On** / **Off**) — isinasara ang popup ng pang-araw-araw na gantimpala para hindi maantala ang mahabang session.

May **?** na button ang bawat setting na nagpapaliwanag dito. Tumatakbo lang ang Awtomatikong Pag-ani habang nasa mundo ka, buhay, at wala sa labanan.
