# Awtomatikong Pag-ani

Awtomatikong inaani ang mga life-resource node — halamang-gamot, mineral, kahoy, hiyas, at iba pa. Pumili ng uri ng resource at ang Awtomatikong Pag-ani ay lalakad papunta at mag-aani ng bawat node ng uring iyon na malapit, kaya puwede kang mag-farm nang walang kamay.

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa **May mod**.
2. Tumayo malapit sa mga resource na gusto mong i-farm at buksan ang window ng **Awtomatikong Pag-ani** mula sa overlay ng Stellar.
3. Awtomatikong mapupuno ang listahan ng **Mga Uri ng Resource sa Malapit**. I-click ang uring gusto mo — may ▶ na nagmamarka sa naka-lock na uri.
4. Pindutin ang **Simulan**. Ang Awtomatikong Pag-ani ay lalakad sa bawat node ng uring iyon at aanihin ito, pagkatapos ay lilipat sa susunod. Pindutin ang **Ihinto** anumang oras.

## Mga Opsyon

- **Focus mode** — gumagastos ng Focus para sa mas bihira at mas mataas ang halagang ani. Mahigpit ito: kapag naubos ang Focus, awtomatiko itong hihinto sa halip na lumipat sa normal na pag-ani.
- **Awtomatikong isara ang mga popup ng gantimpala** — isinasara ang popup ng pang-araw-araw na gantimpala para hindi maantala ang mahabang session na walang bantay.

Tumatakbo lang ang Awtomatikong Pag-ani habang nasa mundo ka, buhay, at wala sa labanan.
