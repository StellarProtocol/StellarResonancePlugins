# ダンジョンハブ

すべてのダンジョンを1つのウィンドウにまとめました。ダンジョンと難易度を選んで、ソロで入場、マッチング開始、またはパーティーで入場できます。NPCのところまで歩く必要はありません。さらに、ゲームの全画面の入場確認を、誰が準備完了かがわかる小さなウィンドウに置き換えます。

![ダンジョンハブ](media/hub.png)

## はじめに

1. プラグインをインストールし、ゲームを**Mod有効**で起動します。
2. キャラクターでログインし、次のどれかで**ダンジョンハブ**を開きます。
   - ゲームのEscメニューの右側にある**ダンジョンハブ**ボタン
   - Stellarランチャーの**ダンジョンハブ**タイル
   - 自分で割り当てたホットキー（下の「ホットキー」を参照）
3. タブを選び、左側でダンジョンを選んでから、右側で難易度と**参加方法**を選びます。

ヘッダーには、ソロかパーティー参加中か（リーダーかどうかも）が表示されます。ウィンドウは前回使ったタブで開きます。

## ダンジョンを選ぶ

ハブには5つのタブがあります：**ダンジョン**、**レイド**、**ワールドボス**、**討伐**、**その他**。

**ダンジョン**

- 一番上の**本日開放**には、今日開いている「不安定」ダンジョンが**不安定**の印つきで並びます。通常のダンジョンはその下の**ダンジョン**に続きます。今日開いている不安定ダンジョンがないときは、見出しは表示されません。
- **難易度**で**ノーマル**、**ハード**、**マスター**から選びます。**マスター**を選ぶと20段階のレベルが表示されます。
  - 緑 = クリア済み、無地 = 次にクリアするレベル、暗い表示 = 未解放
  - 色つきの下線は、**ソロ**と**マッチング**の両方が使えるレベルの印です。

**レイド**

- 今ゲームで開いているすべてのレイド。レイドにある難易度に応じて**イージー**、**ハード**、**ナイトメア**を選べます。

**タイルの見方**

- **推奨**：この難易度でゲームが推奨しているスコア。
- **あなたのスコア**：推奨に届いていれば緑、足りなければ黄色で表示されます。
- **初回クリア**：初回クリア報酬がまだ受け取れるか（**受取可能**）、もう**受取済み**か。
- **残り報酬**：報酬がもらえる残り回数。0でも入場はできますが、報酬はもらえません。

## 参加方法

パネルの下に3つのボタンがあります。

- **ソロ**：ボットと一緒に、ひとりで入場します。
- **マッチング**：自動マッチングです。マッチング中は下のバーに**マッチング中**と経過時間、**キャンセル**ボタンが表示されます。
- **パーティー**：パーティーで入場します。

今使えないボタンはグレーになり、その下に理由が表示されます。たとえば「パーティー未参加」や「パーティー3人以上が必要です (現在1人) - マッチングを使ってください」などです。パーティーでは、入場やマッチングを始められるのはリーダーだけです。

## ワールドボス・討伐・その他

- **ワールドボス**：今週のボス、残り報酬、イベントが開いているか、次にいつ開くかがわかります。ワールドボスは**マッチング**のみです。
- **討伐**：週間の討伐と**ギルド討伐**。ギルド討伐は、開いていてギルドに入っていれば、ここから入場できます（ノーマルまたはハード、**ソロ**または**パーティー**）。
- **その他**：最初は**開拓局の依頼**です。デイリークエストを受注し、今日のイベントといくつ終わったかを確認して、イベントに直接**入場**できます。**掲示板へ行く**を押すと、開拓局の掲示板へ向かいます。
- そのほかのアクティビティには**開く**ボタンがあり、ゲーム本体のそのアクティビティのページが開きます。

## 入場確認

パーティーが入場を始めたときやマッチングが成立したとき、ゲームはふつう画面全体を使って全員に確認を求めます。ダンジョンハブは、その代わりに小さなウィンドウを表示します。5人ダンジョン、レイド、マッチング成立のどれでも使えます。

![入場確認](media/confirm.png)

- 上部にダンジョン名、難易度、カウントダウン。
- **特性**：ダンジョンに特性があるときに表示されます。
- **パーティー**（または4つのグループに分かれた**レイド**）：各プレイヤーのクラス、スコア、状態（**準備完了**、**待機中…**、**辞退**）。自分の行は枠で囲まれます。
- 下部に**確認**と**辞退**。マッチング成立のときは、うっかり押さないよう**辞退**がもう一度確認します（**辞退しますか？**）。リーダーとして入場を始めた場合は、代わりに**入場キャンセル**が表示されます。
- 全員の準備が完了するとウィンドウが閉じて入場します。誰かが辞退したり時間切れになったりすると、誰だったかを表示してから自動で閉じます。
- このウィンドウはほかのStellarウィンドウより常に手前に表示されるので、後ろに隠れることはありません。

## 設定

ダンジョンハブのヘッダーにある歯車ボタン（**⚙**）を押すと、**ダンジョンハブ設定**が開きます。

![ダンジョンハブ設定](media/settings.png)

**入場確認画面**

- **ゲームの入場確認画面を置き換える**：小さなウィンドウのオン・オフを切り替えます。初期状態はオンです。オフにすると、ゲーム本体の全画面の確認が表示されます。
- **5人用をプレビュー** / **レイドをプレビュー**：パーティーを組まなくても、例のプレイヤーでウィンドウを確認できます。プレビューのボタンはウィンドウを閉じるだけです。

**サウンド**（小さな入場確認ウィンドウでだけ鳴ります）

- **開いたときのサウンド**：入場確認ウィンドウが表示されたときに鳴る音。
- **カウントダウン音**：まだ回答していないあいだ、残り10秒から毎秒鳴る音。
- **音量**：両方の音に共通です。音の横の**▶**を押すと試聴できます。
- **サウンドフォルダを開く**：自分の .wav / .mp3 ファイルをここに入れ、サウンドのリストから選びます。**既定**を選ぶと内蔵の音に戻ります。再生できないファイルを選んだときは既定の音が鳴り、設定画面にどのファイルかが表示されます。
- これらの音は、ゲームをミュートしていても、ゲームが裏にあっても聞こえます。

**ウィンドウ**

- **ウィンドウの不透明度を指定**：オフ = ダンジョンハブのウィンドウはテーマのウィンドウ不透明度に従います。オン = すべてのウィンドウに自分で決めた**不透明度**を使います。

## ホットキー

どちらも初期状態では未設定です。**Stellar 設定 → ホットキー**でキーを割り当ててください。

- **ダンジョンハブを開く/閉じる**：ハブを開いたり閉じたりします。
- **ダンジョン: 入場確認の置き換え切替**：小さな入場確認ウィンドウのオン・オフを切り替えます。

## 補足

- ダンジョンハブはワールドにいるときだけ開けます。ログアウトするとウィンドウは閉じます。
- 小さなウィンドウで入場の確認を表示できなかったときは、いつもどおりゲーム本体の確認画面が表示されます。
