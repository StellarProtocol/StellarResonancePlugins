# LoadoutSwitcher

สลับระหว่างโหลดเอาต์ในเกมที่คุณบันทึกไว้ (Role Plans) ได้ด้วยปุ่มลัด

## วิธีใช้งาน

1. ติดตั้งปลั๊กอินแล้วเปิดเกมแบบ **ใช้ม็อด**
2. บันทึกโหลดเอาต์ (Role Plans) ในเกมตามปกติ
3. เปิด **การตั้งค่า Stellar → ปุ่มลัด** ขยายกลุ่มของปลั๊กอินแล้วผูกปุ่มให้กับ **ใช้โหลดเอาต์ 1** ถึง **ใช้โหลดเอาต์ 8** (ค่าเริ่มต้นยังไม่ได้ผูกปุ่ม) ปุ่มลัดที่ *n* จะใช้โหลดเอาต์ลำดับที่ *n* ในรายการที่คุณบันทึกไว้

![Hotkey bindings](media/loadoutswitcher-hotkeys.png)

4. กดปุ่มลัดในโลกเกม — ปลั๊กอินจะสลับผ่านขั้นตอนโหลดเอาต์ของเกมเอง

## การคัดลอกโหลดเอาต์

เปิดหน้าต่าง Loadout Switcher โหลดเอาต์ทุกตัวยกเว้นตัวที่คุณสวมอยู่จะมีปุ่มที่แสดงชื่อโหลดเอาต์ปัจจุบันของคุณ เช่น "← Ici-LF" คลิกปุ่มนี้บนแถวที่ต้องการเขียนทับ ตรวจสอบคำถาม ("เขียนทับด้วย Ici-LF?") แล้วกด ✓

- มันจะคัดลอกสิ่งที่คุณสวมอยู่ตอนนี้: อุปกรณ์ โมดูล สกิล ทาเลนต์ Battle Imagine และการผูก Deep-Slumber ชื่อของโหลดเอาต์จะยังคงเดิม
- หากคุณมีการเปลี่ยนแปลงที่ยังไม่บันทึก หรือการคัดลอกจะเปลี่ยนคลาสของโหลดเอาต์นั้น หน้ายืนยันจะแสดงข้อความเตือนก่อน
- เกมจะยืนยันด้วยข้อความของตัวเอง "Loadout saved successfully!" หากเกมปฏิเสธ (เช่น ขณะอยู่ในการต่อสู้) จะไม่มีอะไรเปลี่ยนแปลง

## เคล็ดลับ

- เปิด **ไม่ส่งปุ่มลัดต่อไปยังเกม** ที่ด้านบนของแผงปุ่มลัด เพื่อไม่ให้ปุ่มที่คุณผูกไว้ไปกระตุ้นการกระทำในเกมพร้อมกันขณะที่คุณสลับโหลดเอาต์

## ผลตอบรับ

ผลการสลับจะใช้แบนเนอร์แจ้งเตือนของเกมเอง: แบนเนอร์สำเร็จเมื่อแผนถูกนำไปใช้ และการแจ้งเตือนป้องกันเมื่อไม่สามารถสลับได้ในตอนนี้ (เช่น ขณะมีการสลับอื่นกำลังทำงานอยู่ หรือ API ของโหลดเอาต์ยังไม่พร้อม)
