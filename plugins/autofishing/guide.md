# Auto Fishing

Fully automates the fishing minigame — from casting to catch — so you can leave it running
unattended.

## How to use

1. Install the plugin and launch the game **Modded**.
2. Go to a fishing spot with a rod equipped and open the Auto Fishing window from the
   Stellar overlay.
3. Enable it. The plugin casts, plays the tension minigame, and lands the catch on its own,
   then starts over.

## Options

- **Tension control** is configurable — tune how aggressively the plugin plays the
  reel-in minigame.
- **Auto rod change** swaps to your next rod so a worn-out rod doesn't stop the session.
