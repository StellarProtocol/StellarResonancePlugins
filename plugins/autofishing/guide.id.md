# Pancing Otomatis

Mengotomatiskan sepenuhnya minigame memancing — dari melempar sampai menangkap — jadi kamu bisa membiarkannya berjalan tanpa diawasi.

## Cara pakai

1. Pasang plugin lalu jalankan game dalam mode **Modded**.
2. Pergi ke titik memancing dengan joran terpasang, lalu buka jendela Pancing Otomatis dari overlay Stellar.
3. Aktifkan. Plugin akan melempar, memainkan minigame tegangan, dan mengangkat tangkapannya sendiri, lalu mengulang dari awal.

## Opsi

- **Kontrol Tegangan** dapat disesuaikan — atur seberapa agresif plugin memainkan minigame menggulung senar.
- **Ganti Joran Otomatis** berpindah ke joran berikutnya supaya joran yang aus tidak menghentikan sesi.
