# フォトスタジオ

美しいスクリーンショットを撮ろう: インターフェースを隠し、自由カメラでシーン内のどこへでも移動し、瞬間を
止め、誰でもポーズを取らせ、縦長や正方形で撮影し、ルックとライトを加えて——高解像度の写真として保存できます。

![フォトスタジオのパネル](media/photostudio-inworld.png)

## クイックスタート

1. プラグインをインストールし、ゲームを **Modded** で起動します。
2. **Shift+F10** を押してフォトスタジオのパネルを開きます。
3. **F10** を押して写真を撮ります。写真はスクリーンショットフォルダーに保存されます(撮影タブ → フォルダー)。
4. **Ctrl+F10** ですべてを隠してクリーンな画面にできます。

すべてのホットキーは **Stellar 設定 → ホットキー** で変更できます。

## タブ

- **撮影** — 解像度(画面の1倍・2倍・4倍)、写真の **形**(画面、縦長9:16、4:5、2:3、正方形1:1、横長21:9)、
  PNGかJPG、フォルダー、撮影中に何を隠すか。
- **ルック** — カラー、露出、コントラスト、ホワイトバランス、被写界深度など。お気に入りのルックはプリセット
  として保存できます。
- **カメラ** — 自由カメラ、シーン(停止/リセット)、移動の設定、人物のポーズ付け。
- **ライト** — ランプ、そして1人用のキーライトとリム。
- **プリセット** — ルックの読み込み、保存、名前変更、共有。

## 非表示にする

**撮影** タブの **非表示** グループには、ゲーム本体の写真画面と同じ項目が同じ順番で並んでいます:

- **自分** と **自分のスピリットエコー** は自分のキャラクターとスピリットエコーを——自分の画面でのみ——隠します。
  移動も戦闘も続けられ、他のプレイヤーからはあなたが見えたままです。
- **他の冒険者**、**NPC**、**敵**、**収集物**、**他のスピリットエコー** は、それらを自分の画面で隠します。
- **フレンド**、**パーティー**、**ギルド** は、他の冒険者を表示していても、それらのプレイヤーを本当に隠します。
  非表示にしたグループが常に優先されます: ギルドを非表示にすると、フレンドでもあるギルドメンバーは非表示に
  なります。パーティーを表示していれば、パーティーメンバーは表示されたままです。
- **武器** は自分だけでなく、すべてのプレイヤーの武器を隠します。
- **エフェクト** は、誰が発生させたかでスキル・バフ・ヒットエフェクトを隠します: **自分**(自分、自分のペット、
  自分のBattle Imagineによるもの)、**パーティー**、**他のプレイヤー**、**モンスター**(ボスの警告エリアを含む)。
  滝やランプなどの風景は決して隠れません。ゲームが誰にも紐づけていない一部のエフェクトは常に表示されます。

これらはパネルを開いている間と、すべての写真に適用されます。**カメラ** タブの **開始時に自分を隠す** と
**開始時にエフェクトを隠す** は、自由カメラがオンになった瞬間に同じことを行います(エフェクトは撮影タブの
切り替えに従います)。オフにする——またはフォトスタジオを閉じる——とすべて元に戻ります。1.6.0の非表示設定は
引き継がれます。**Ctrl+F10** は、Stellarのオーバーレイを含むすべてを隠したままです。

## ReShade

フォトスタジオは **ReShade** のエフェクトを画面上と写真の両方で使えます。

1. Stellarランチャーで、フォトスタジオのページを開き、**Dependencies** の下の **ReShade** にチェックを入れた
   ままにします(Linux / Protonの場合は **Microsoft shader compiler** にもチェックを入れたままにします)。
   ランチャーはゲーム起動前にそれらをダウンロードして検証します。
2. ゲームを **Modded** で起動します。ReShadeはModded起動時のみ使用され、**Vanilla** 起動ではReShadeは使われません。
3. **ルック** タブ → **ReShade** グループを開きます: **ReShadeを使う** をオンにし、**プリセット** を選び
   (エフェクトなしにするには **なし**)、エフェクトのオン/オフを切り替えます。
4. **プリセット** では、ワンクリックで出来合いのルックを追加でき、**シェーダーパック** では、それらが使う
   エフェクトパックをダウンロードできます。ダウンロードしたプリセットはすぐにプリセット一覧に表示されます。

各エフェクトはReShade自体のメニュー(デフォルトでは **Home**)で微調整できます。縦長・正方形・横長の写真では
深度を必要とするエフェクトは省かれます。フォトスタジオはそうなったときに知らせてくれます。

## 自由カメラ

**Alt+F10**(または **フリーカメラ** ボタン)を押してカメラを操作します。

- **周回**(デフォルト): **右クリック** で人物の周りを回転、**マウスホイール** で近づいたり離れたり、
  **Q / E** で下 / 上に移動。**クリック** で別のキャラクターを周回対象にでき、**Backspace** で自分に戻ります。
- **飛行**: **Tab** を押してから **WASD** で移動、**右クリック** で視点操作。
- **Z / C** でカメラを傾け、**Shift + ホイール** でズーム(視野角)、**R** でゲームの視点に戻ります。
- **]** でズームイン、**[** でズームアウト(押し続けると続きます)、**\\** で視野角をリセットします。
  **ルック** タブにも **視野角** のスライダー(10〜100°)があります。キーは画面上に表示されます。
- **Space** でシーンを停止し、**H** でキーヒントを隠し、**Esc** または **Alt+F10** で自由カメラを終了します。

## シーンを停止する

自由カメラでの **Space**(または **カメラ** タブの **停止**)は、あなたの画面上でゲーム全体を——全員、すべての
スキルとエフェクト、そして自分のキャラクターも——一時停止します。自由カメラを終了してもワールドは停止したまま
で、**再開** または再度 **Space** を押すと再開します。サーバー側ではゲームは進み続けます: 戦闘は続き、停止中に
起きたことは再開したときに反映されます。停止中に倒されたモンスターは、再開するまで画面に残ります。

## 人物のポーズ付け

カメラタブの **人物** グループで、**‹ ›** で誰かを選びます(または自由カメラでクリックします):

- **ポーズ** — エモートを選び、**モーメント** をドラッグして正確な瞬間に合わせます。▶ / ❚❚ で再生・一時停止。
- **表情** — 変更するまで続く表情。
- **頭 / 目** — カメラを見る(**レンズ**)、自由に向ける(**自由**)、通常にするかを選び、ロックできます。
  **自由** では、グリッド上のドットをドラッグして狙いを定めるか、矢印で微調整します。**ステップ**
  (細かく・標準・粗く)で矢印1回あたりの移動量が決まります。
- **回転** — 向きたい方向にキャラクターを向けます。

他のプレイヤーやNPCは自分だけに見えるコピーとしてポーズを取ります。実際の本人は、シーンをリセットするまで
隠れたままです。

## ライト

**ライト** タブ:

- **＋ カメラ位置にランプ**(または自由カメラでの **L**)で、カメラのある位置にランプを置きます。
  **Shift+L** で選択中のランプをそこに移動します。最大8個のランプを、それぞれ色・強さ・範囲を自由に設定して、
  選択した人物の周りに配置できます。
- **人物の明るさ** で、ランプがキャラクターをどれだけ強く色づけするかを設定します(どのランプの近くにいても、
  他の人物も色づけされます)。
- **人物ライト** は、1人に、選んだ方向からの **キーライト** と、髪・頭防具・武器に色づく **リム** を与えます。

## シーンを終える

**カメラ** タブの **シーンをリセット** は、停止を解除し、ポーズ付けしたコピーとライトを取り除き、全員を通常
状態に戻します。ゾーン変更、カットシーン、フォトスタジオをオフにすることでも同じことが起こります。

## 最小化と終了

- パネルの **–** は、パネルを小さな帯に縮小するだけで、何も変更しません。
- パネルまたは帯の **✕**、または **Ctrl+Shift+F10** で、フォトスタジオを完全に終了します: 自由カメラを終了し、
  停止を解除し、ポーズ付けした人物とランプをリセットし、隠していたものをすべて表示します。何か実行中の場合は
  先に確認を求め、終了する内容を一覧表示します。
- フォトスタジオが閉じている間、シーンとカメラのピルには再度開くためのキーが表示されます。
