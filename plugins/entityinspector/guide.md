# EntityInspector

Inspect any entity in the world: identity, attributes, equipped gear and skill book — in a
window you can open on anyone.

![Entity inspector](https://cdn.revette.io/plugins/entityinspector/media/entity-inspector.png)

## How to use

1. Install the plugin and launch the game **Modded**.
2. Open an inspection from either entry point:
   - the **magnifier button** on a profile card, or
   - the **Inspect** item on a CombatMeter row (with CombatMeter installed).
3. The window shows the entity's identity, attributes, gear with details, and skill book.
   Drag the 3D portrait to rotate it — vertical rotation is unclamped, so look from any angle.

## Tips

- The inspector window always opens on top of other windows, so it never hides behind the
  meter mid-fight.
