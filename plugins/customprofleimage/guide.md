# Custom Profile Image

Use any PNG as your in-game avatar or namecard — no in-game camera photo required. Works even if
your Windows account, your picture, or the game itself is installed in a folder with non-English
characters.

![Custom Profile Image window](media/customprofileimage.png)

## How to use

1. Install the plugin and launch the game **Modded**, then enter the world.
2. Open the **Custom Profile Image** window from the Stellar overlay.
3. **Select the image** you want to apply to your Avatar or Namecard. A native PNG file picker
   opens — if you don't see it, it may be behind the game window: press **Alt+Tab** to bring it
   forward, or run the game in **Borderless / Windowed** mode.
4. Press **Make Avatar/Namecard** — the status shows **Ready**.
5. In-game, use an **Avatar / Namecard change ticket** from your inventory, or go to the **guild's
   Avatar / Namecard change device**.
6. **Take a shot without adjusting anything.** The preview shows the picture that will be uploaded.
7. Press the game's **upload button once** — only once; don't press it repeatedly.

One selected image serves both: the plugin automatically applies it as your **Avatar** or
**Namecard** depending on which one you're changing in-game.

## Recommended image sizes

- **Avatar:** 300×300 px square PNG
- **Namecard:** 468×774 px portrait PNG

Staying close to these avoids the game scaling or cropping your picture. The in-window preview may
not exactly match the final result — check the in-game preview before you confirm.
