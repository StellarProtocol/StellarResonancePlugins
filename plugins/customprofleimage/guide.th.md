# รูปโปรไฟล์ที่กำหนดเอง

ใช้ PNG ใดก็ได้เป็นรูปโปรไฟล์หรือนามบัตรในเกมของคุณ — ไม่ต้องถ่ายภาพจากกล้องในเกม ใช้งานได้แม้
บัญชี Windows รูปภาพ หรือตัวเกมเองจะติดตั้งอยู่ในโฟลเดอร์ที่มีอักขระที่ไม่ใช่ภาษาอังกฤษ

![Custom Profile Image window](media/customprofileimage.png)

## วิธีใช้งาน

1. ติดตั้งปลั๊กอินแล้วเปิดเกมแบบ **Modded** จากนั้นเข้าสู่โลกเกม
2. เปิดหน้าต่าง **รูปโปรไฟล์ที่กำหนดเอง** จากโอเวอร์เลย์ของ Stellar
3. **เลือกรูปภาพ** ที่ต้องการใช้กับรูปโปรไฟล์หรือนามบัตรของคุณ หน้าต่างเลือกไฟล์ PNG ของระบบจะ
   เปิดขึ้น — หากไม่เห็น อาจซ่อนอยู่หลังหน้าต่างเกม ให้กด **Alt+Tab** เพื่อนำมาไว้ด้านหน้า หรือ
   เล่นเกมในโหมด **ไร้ขอบ / หน้าต่าง**
4. กด **สร้างรูปโปรไฟล์/นามบัตร** — สถานะจะแสดงคำว่า **พร้อมแล้ว**
5. ในเกม ใช้ **การ์ดเปลี่ยนรูปโปรไฟล์/นามบัตร** จากกระเป๋าของคุณ หรือไปที่ **อุปกรณ์เปลี่ยนรูป
   โปรไฟล์/นามบัตรของกิลด์**
6. **ถ่ายภาพโดยไม่ต้องปรับแต่งอะไร** ตัวอย่างจะแสดงรูปภาพที่จะถูกอัปโหลด
7. กด **ปุ่มอัปโหลดของเกมเพียงครั้งเดียว** — เพียงครั้งเดียวเท่านั้น อย่ากดซ้ำ ๆ

รูปภาพที่เลือกไว้รูปเดียวใช้ได้กับทั้งสองอย่าง: ปลั๊กอินจะนำไปใช้เป็น **รูปโปรไฟล์** หรือ
**นามบัตร** โดยอัตโนมัติ ขึ้นอยู่กับว่าคุณกำลังเปลี่ยนอันไหนอยู่ในเกม

## ขนาดรูปภาพที่แนะนำ

- **รูปโปรไฟล์:** PNG สี่เหลี่ยมจัตุรัส 300×300 px
- **นามบัตร:** PNG แนวตั้ง 468×774 px

การใช้ขนาดใกล้เคียงกับนี้จะช่วยไม่ให้เกมปรับขนาดหรือครอปรูปของคุณ ตัวอย่างในหน้าต่างอาจไม่ตรงกับ
ผลลัพธ์สุดท้ายเป๊ะ ๆ — ตรวจสอบตัวอย่างในเกมก่อนยืนยัน
