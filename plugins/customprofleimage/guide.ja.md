# カスタムプロフィール画像

ゲーム内カメラでの撮影なしに、好きなPNGをアバターやネームカードとして使用できます。Windowsアカウント、画像、またはゲーム自体が英数字以外の文字を含むフォルダーにインストールされていても動作します。

![Custom Profile Image window](media/customprofileimage.png)

## 使い方

1. プラグインをインストールし、**Mod有効** でゲームを起動してからワールドに入ります。
2. Stellarオーバーレイから **カスタムプロフィール画像** ウィンドウを開きます。
3. **画像を選択します**。アバターまたはネームカードに適用したい画像です。標準のPNGファイル選択ダイアログが開きます — 表示されない場合はゲームウィンドウの裏に隠れている可能性があるため、**Alt+Tab** で前面に出すか、ゲームを **ボーダーレス／ウィンドウ** モードで実行してください。
4. **「アバター／ネームカードを作成」** を押すと、ステータスに **「準備完了」** と表示されます。
5. ゲーム内で、インベントリの **アバター／ネームカード変更チケット** を使うか、**ギルドのアバター／ネームカード変更装置** に行きます。
6. **何も調整せずに撮影します。** プレビューにアップロードされる画像が表示されます。
7. **アップロードボタンを一度だけ押します。** 連打しないでください。

選択した1枚の画像が両方に使われます：ゲーム内でどちらを変更しているかに応じて、プラグインが自動的に **アバター** または **ネームカード** として適用します。

## 推奨画像サイズ

- **アバター:** 300×300 px の正方形 PNG
- **ネームカード:** 468×774 px の縦長 PNG

このサイズに近づけることで、ゲーム側での拡大縮小やトリミングを避けられます。ウィンドウ内のプレビューは最終結果と完全には一致しない場合があるため、確定前にゲーム内プレビューを確認してください。
