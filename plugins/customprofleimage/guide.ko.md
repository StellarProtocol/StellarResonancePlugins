# 프로필 이미지

인게임 카메라 촬영 없이도 원하는 PNG를 아바타나 명함으로 사용하세요. Windows 계정, 사진, 또는
게임 자체가 영문이 아닌 문자가 포함된 폴더에 설치되어 있어도 작동합니다.

![Custom Profile Image window](media/customprofileimage.png)

## 사용 방법

1. 플러그인을 설치하고 **모드 적용** 상태로 게임을 실행한 뒤 월드에 접속하세요.
2. Stellar 오버레이에서 **프로필 이미지** 창을 엽니다.
3. 아바타나 명함에 적용할 **이미지를 선택**하세요. 기본 PNG 파일 선택 창이 열립니다 — 보이지
   않는다면 게임 창 뒤에 가려져 있을 수 있으니 **Alt+Tab**으로 앞으로 가져오거나, 게임을
   **테두리 없음 / 창 모드**로 실행하세요.
4. **아바타/명함 만들기**를 누르세요 — 상태가 **준비됨**으로 표시됩니다.
5. 게임 안에서 인벤토리의 **아바타 / 명함 변경권**을 사용하거나, **길드의 아바타 / 명함 변경
   장치**로 이동하세요.
6. **아무것도 조정하지 말고 촬영하세요.** 미리보기에 업로드될 사진이 표시됩니다.
7. 게임의 **업로드 버튼을 한 번만** 누르세요 — 반복해서 누르지 마세요.

선택한 이미지 하나로 두 가지를 모두 처리합니다: 지금 게임에서 어떤 것을 변경하는지에 따라 플러그인이
자동으로 **아바타** 또는 **명함**으로 적용합니다.

## 권장 이미지 크기

- **아바타:** 300×300 px 정사각형 PNG
- **명함:** 468×774 px 세로형 PNG

이 수치에 가깝게 유지하면 게임이 사진을 축소하거나 잘라내는 것을 방지할 수 있습니다. 창 안의
미리보기가 실제 결과와 다를 수 있으니, 확정하기 전에 게임 내 미리보기를 확인하세요.
