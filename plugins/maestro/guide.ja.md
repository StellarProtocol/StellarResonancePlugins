# Maestro

Star Resonance シーズン3のバンド（ミュージシャン）楽器向けの MIDI 自動演奏プラグインです。`.mid` ファイルをフォルダに入れて曲を選ぶだけで、Maestro が召喚した楽器でソロでもグループでも自動演奏します。プレイリスト、グループ同期、ローカルサウンドプレビューにも対応しています。

![ライブラリ、MIDI自動演奏、プレビューのウィンドウを開いてワールド内で演奏中](media/maestro-in-world.png)

## はじめに

1. プラグインをインストールし、ゲームを **Mod有効** で起動します。
2. Stellar ランチャー（Plugins グループ）から **Maestro** を開きます。バンドツールはワールド内でのみ使用できます。
3. `.mid` / `.midi` ファイルをゲームの `midi\` フォルダに入れます — Maestro が自動でこのフォルダを作成し、**ライブラリ** ウィンドウにそのパスを表示します。移動した場合は **フォルダを再スキャン** または **場所を開く** を使ってください。
4. ゲーム内でフリープレイ楽器を召喚し、**ライブラリ** から曲をキューに追加して ▶ を押します。

## 曲を再生する

メインウィンドウがプレイヤー本体です: プレイリスト、再生中のキュー、トランスポートコントロールがあります。

![MIDI自動演奏 — プレイリスト、キュー、再生コントロール](media/auto-player.png)

- 名前付きの **プレイリスト** を作成し、キューの並び替えもできます。ヘッダーには現在の曲と再生位置が表示されます。
- **自動送り**、**ループ**（オフ / 全曲 / 1曲）、**シャッフル**、**曲間の間隔** はすべてワンクリックで切り替えられます。
- ステータス行には、再生中の曲のライブ位置と音符数が表示されます。

## 曲を探す

![ライブラリ — MIDIフォルダを閲覧し、曲をキューに追加](media/library.png)

- MIDIフォルダ全体を閲覧し、名前で **検索** して、曲をクリックするとキューに追加されます。
- 再生は一度に1つの楽器のみを演奏するので、演奏したいステムだけをキューに入れてください。

## 再生前にプレビューする

楽器を召喚しなくても、**実際のゲーム内楽器音** で曲を試聴できます — プレビューは自分にだけ再生されるので、周囲の人には聞こえません。

![MIDIプレビュー（ローカル） — 実際のゲーム内楽器音で試聴](media/preview.png)

- パートごとに1行表示され、個別の **ミュート** と **サステイン** モードがあるので、曲の仕上がりを正確に確認できます。
- **楽器同期** はライブのバンドプレイヤーを待ってから追従し、自分が演奏するパートをミュートします — 他の人と一緒に演奏する練習に便利です。

プレビューでは複数ステムの命名が重要になります: 曲の各パートに同じベース名を付け、末尾に楽器名をかっこで囲んで終わらせると、プレビューはそのうちどれか1つを選んだときに **セット全体** を読み込みます。

```
Song (Piano).mid   Song (Guitar).mid   Song (Bass).mid   Song (Bass 2).mid   Song (Drum).mid
```

`(Bass 2)` のような重複は、同じ楽器音の別トラックになります。

## 曲ごとの設定とグループ演奏

細かい調整やグループオプションは **設定** から開けます。

![設定 — 曲ごとの設定、ネットワーク同期、合奏オプション](media/settings.png)

- **曲ごとの設定**: 移調、ノート保持、テンポ%、最大ノート数（ポリフォニー上限）、リストライク間隔、モニター音量、サステイン強制、MIDIからのトーン／奏法適用。
- **ネットワーク同期モード** はノートを事前に送信するので、ノートが密集していても周囲のリスナーにはより安定した演奏が届きます。
- **合奏**: グループ共通の拍（ダウンビートへのカウントイン）に再生をロックし、任意で合奏テンポに合わせ、招待を自動承諾して全員が一緒にスタートできます。あらかじめゲーム内で合奏に参加するか開始しておいてください。

## 合奏で演奏する

合奏モードはパーティー全体の演奏を同じ拍にロックするので、複数のプレイヤーが同じ曲の異なるパートを同期して一緒に演奏できます。全員が **同じパーティー** にいる必要があります。

1. **合奏同期をオンにする。** **設定** で、全プレイヤーが **合奏に同期** を有効にします。**合奏の招待を自動承諾** も任意でオンにすれば、招待をいちいち手動で承諾する必要がなくなります。
2. **各プレイヤーがパートを選んで ▶ を押す。** 演奏するステムを選んで再生を押します — Maestro はすぐに再生を始めず、**「合奏を待機中…」** と表示して待機します。
3. **パーティーリーダーがゲーム内で合奏を開始する。** これはゲーム本来の合奏開始操作です。
4. **全員が同期して演奏する。** 待機していた全プレイヤーが、合奏の拍にロックされたダウンビートで一斉に演奏を始めます。

フルバンド編成にするには、各プレイヤーが同じ曲の **異なる** パート（ギター、ベース、ドラム、ピアノ）をキューに入れ、任意で **合奏テンポに合わせる** をオンにすると、再生が合奏のBPMに追従します。事前に **プレビュー** を使って、セット全体がどう組み合わさるか確認しておきましょう。

## MIDIファイルを準備する

Maestro は MIDI に書かれた通りに演奏するので、少し準備しておくとゲーム内の楽器でも曲が正しく響くようになります。

### エフェクト（トーンと奏法）

設定で **MIDI楽器からトーン／奏法を適用** をオンにすると、Maestro は **そのステムのトラックに割り当てられた楽器（プログラム）** からギター／ベースのエフェクトを決定します。DAW でそのトラックの General MIDI楽器を設定してください:

**ギターステム**

| この GM 楽器を割り当てる | プログラム # | 再生エフェクト |
|---|:--:|---|
| Nylon / Steel / Jazz / Clean Electric Guitar | 25–28 | Clean |
| Muted Guitar | 29 | Muffled (palm-mute) |
| Overdriven Guitar | 30 | Overdrive |
| Distortion Guitar | 31 | Distortion |
| Guitar Harmonics | 32 | Harmonics |

**ベースステム**

| この GM 楽器を割り当てる | プログラム # | 再生エフェクト |
|---|:--:|---|
| Acoustic / Finger / Pick / Fretless Bass | 33–36 | Clean |
| Slap Bass 1 / 2 | 37 / 38 | Slap |
| Synth Bass 1 / 2 | 39 / 40 | Overdrive |

- プログラム番号は DAW が表示する **1〜128** の値です。わからない場合は **楽器名** で照合してください。
- 読み取られるのはステムの **メイン楽器** のみなので、ステムごとに楽器は1つにしてください。トラック途中のプログラムチェンジは、それ以降のエフェクトを切り替えます。
- エフェクトが適用されるのは **ギターとベースのみ** です — ピアノとドラムには適用されません。
- エフェクトは実際に召喚している楽器に合わせて調整されます。**ベースにはディストーションがなく**、代わりにOverdrive として再生されます。召喚した楽器が対応していない奏法は通常再生にフォールバックします。
- **Overdrive / Distortion はネットワーク同期ではローカルのみ** です（下記の *既知の制限* を参照）。Muffled、Harmonics、Slap は全員に聞こえます。

### ドラム

ゲームのドラムキットは下記のキーに固定された **9ピースキット** で、Maestro は書かれたノートをそのまま演奏します — General MIDI のドラムを自動変換することは **ありません** ので、ドラムステムは次のキーを使う必要があります:

| MIDIノート | パーツ |
|:--:|---|
| 62 (D4) | クローズハイハット |
| 65 (F4) | キック |
| 69 (A4) | フロアタム |
| 72 (C5) | スネア |
| 74 (D5) | ミッドタム |
| 76 (E5) | ハイタム |
| 77 (F5) | ライド |
| 79 (G5) | オープンハイハット |
| 81 (A5) | クラッシュ |

これ以外のキーのノートは無音になります。標準的な General MIDI ドラムトラックから始める場合は、通常のGMノートをこれらのキーに再マッピングしてください — キック（GM 35/36）→ **F4**、スネア（38/40）→ **C5**、クローズハイハット（42）→ **D4**、オープンハイハット（46）→ **G5**、ライド（51）→ **F5**、クラッシュ（49）→ **A5**、タム → **A4 / D5 / E5**。

### その他のヒント

- **1つの音高につき1ノート:** 各楽器は音高ごとに1ボイスしか鳴らせないため、同じ音高が重なる2つのノートは1つとして扱われます — ユニゾンの重ね打ちは避けてください。
- **音域に注意:** 楽器の演奏可能音域外のノートは無音になります。パートを音域内に収めるには **移調**（設定）を使ってください。
- **音量は再現されません:** すべてのノートは一定の音量で再生されるため、ベロシティやダイナミクスは反映されません。
- MIDI の **タイプ 0 または 1** のファイルに対応しています。

## 既知の制限

**Overdrive / Distortion は他のプレイヤーに届きません — これはゲーム側のバグであり、Maestro 側では修正できません。** ゲームはギター／ベースの overdrive/distortion の *トーン* を自分のクライアントでしかレンダリングせず、周囲のプレイヤーには送信しません。そのため **ネットワーク同期がオン** のときは他の全員に Clean で聞こえ、ネットワーク同期が **オフ** の場合でも、ディストーションが聞こえるのは *あなただけ* です — どちらのモードでも他のプレイヤーにあなたの overdrive/distortion が聞こえることはありません。Maestro のどの設定でもこれは変わらず、修正はゲーム側次第です。*奏法*（Muffled、Harmonics、Slap）はこの影響を受けず、全員に聞こえます。ディストーションが重要な曲では、ネットワーク同期を **オフ** にして、少なくとも自分には正しく聞こえるようにしてください。
