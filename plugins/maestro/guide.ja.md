# Maestro

Star Resonance シーズン3のバンド（ミュージシャン）楽器向けの MIDI 自動演奏プラグインです。`.mid` ファイルをフォルダに入れて曲を選ぶだけで、Maestro が召喚した楽器でソロでもグループでも自動演奏します。プレイリスト、グループ同期、ローカルサウンドプレビューにも対応しています。

![Maestro ウィンドウを開いてワールド内で演奏中](media/maestro-in-world.png)

## はじめに

1. プラグインをインストールし、ゲームを**Mod有効**で起動します。
2. Stellar ランチャー（プラグイングループ）から**Maestro**を開きます。バンドツールはワールド内でのみ使用できます。
3. `.mid` / `.midi` ファイルをゲームの `midi\` フォルダに入れます — このフォルダは Maestro が自動で作成します。**ライブラリ**の**フォルダーを開く**でそのフォルダをすぐ開けて、**再スキャン**で追加したファイルを読み込めます。
4. ゲーム内でフリープレイ楽器を召喚し、**+ 追加**からライブラリの曲を選んで、**再生**を押します。

## Maestro Link — Webサイトからバンドで演奏

Maestro Link を使えば、ゲーム内の合奏なしでバンド全員が一緒に演奏できます。バンドリーダーが Webサイト [maestro.stellarresonance.app](https://maestro.stellarresonance.app) でルームを作り、曲と担当パートを決めると、各プレイヤーのキャラクターが自動で楽器を装備し、バンド全体と同期して自分のパートを演奏します。

![ワールド内で Maestro Link の曲をピアノで演奏中](media/link-in-world.png)

### ルームに参加する

1. **6文字のルームコード**を用意します — Webサイトでルームを作成するか、バンドリーダーから教えてもらいます。
2. ゲーム内で **Maestro** → **Maestro Link** を開きます。
3. 入力欄にコードを入力して **参加**を押します。
4. これで完了です — ルームで曲が再生されると、キャラクターが自動で自分のパートを演奏します。

**使い方**パネルにはこの手順がまとめてあり、**ウェブサイトを開く**で Maestro Link のサイトを開けます。

![Maestro Link — ルームコードを入力して参加を押す](media/link-join.png)

### ルーム参加中

![ルーム参加中の Maestro Link — ルーム、再生中の曲、プレイヤー一覧](media/link-connected.png)

- **ルーム**には、ルームコードとルーム名、Ping、自分が担当するパートが表示されます。
- **再生中**には、今の曲とその進行状況、**次の曲**が表示されます。
- **プレイヤー**には、ルームにいる全員の名前、楽器、状態、Ping が並びます。状態は**演奏中**、**準備OK**、**待機**、**問題**のいずれかです。*問題*が出るのは、今まさに演奏中のパートが演奏できないときだけです — まだ楽器を持っていないのは問題ありません。次の曲で Link が自動で装備します。**隠す**で一覧を折りたためます。
- **自分のパートを停止**（オレンジ）を押すと、バンドの演奏は続いたまま自分のパートだけお休みします。ボタンは**自分のパートを再開**に切り替わります。
- **切断**（赤）でルームから退出します。ログアウトすると自動的に切断されます。

### Webサイト

Webサイトのルームページでバンドを進行します。参加中のプレイヤー一覧、**Now playing**（一時停止・停止・スキップ・リピート）、そして各パートの担当を選べる曲のキューがあります。1つのパートを複数のプレイヤーに割り当てたり、1人のプレイヤーが同じ楽器の複数のパートを担当したりもできます。**Room settings**（ルーム設定）は全プレイヤーにまとめて適用され、プレイヤーごとに個別に調整することもできます。

![Maestro Link の Webサイト — プレイヤー、Now playing、曲のキュー](media/web-room.png)

## 曲を再生する

メインウィンドウがプレイヤー本体です。上部の**再生中**には今の曲と進行状況が表示され、◀◀ / **再生**（**一時停止**）/ ▶▶ / **停止** ボタンと、次に流れる曲を示す**次:** の行があります。

![メインウィンドウ — 再生中、キュー、4枚のカード](media/auto-player.png)

**キュー**

- ドロップダウンでプレイリストを選び、**+ 新規**、**名前変更**、**✕**（プレイリストを削除）で管理できます。
- **曲をドラッグ**して並び替え、各行の **✕** でその曲を外せます。
- 別のプレイリストに切り替えても、再生中の曲は止まりません — 別のプレイリストで曲を選んで**再生**を押すまで、そのまま流れ続けます。
- キューの下のアイコンで**自動で次の曲**、**ループ**（オフ / 全曲 / 1曲）、**シャッフル**を切り替えます。アイコンにカーソルを合わせると、その名前と設定が**キュー**の見出しに表示されます。
- **シャッフル**はプレイリストの全曲をランダムな順番で1回ずつ再生します。ループがオフなら最後の曲で止まり、ループが全曲なら1周ごとに順番を混ぜ直します。**次:** の行には、実際に次に流れる曲が常に表示されます。
- **+ 追加**でライブラリが開きます。

下部の4枚のカードから、**ライブラリ**、**Maestro Link**、**プレビュー**、**設定**の各ウィンドウを開けます。各カードには曲数やルームに参加中かどうかなど、ひと目でわかる状態も表示されます。

## 曲を探す

![ライブラリ — 曲を検索し、クリックしてプレイリストに追加](media/library.png)

- 名前で**検索**（✕ で検索をクリア）し、**再スキャン**で新しいファイルを読み込み、**フォルダーを開く**で MIDI フォルダを開けます。
- **曲をクリック**すると、今のプレイリストに追加されます。その行が緑色に光って**追加済み**と表示され、下の行でも *✓「Bad Apple (Piano)」をPlaylist 1に追加 · 11曲* のように確認できます。
- 再生は一度に1つの楽器のみを演奏するので、演奏したいステムだけを追加してください。

## 再生前にプレビューする

楽器を召喚しなくても、**実際のゲーム内楽器音**で曲を試聴できます — プレビューは自分にだけ再生されるので、周囲の人には聞こえません。

![プレビュー — 試聴中の曲、バンド同期の設定、ステムごとの行](media/preview.png)

- **試聴**には、キューで選んだ曲とその進行状況、**プレビュー**と**停止**ボタンがあります。
- **バンドと同期**: **楽器同期**は自分のバンド演奏が始まるのを待ってから、それに合わせて再生します — 自分で演奏するパートはミュートしてください。**同期オフセット**はプレビューを遅らせて、バンドの音と揃えます。**= バンド遅延**を押すと自動で合わせてくれます。
- **ステム**にはファイルごとに1行あり、ミュートの切り替え、楽器、**サステイン**モード、**トーン**のスイッチがあるので、曲の仕上がりを正確に確認できます。

プレビューでは複数ステムの命名が重要になります: 曲の各パートに同じベース名を付け、末尾に楽器名をかっこで囲んで終わらせると、プレビューはそのうちどれか1つを選んだときに**セット全体**を読み込みます。

```
Song (Piano).mid   Song (Guitar).mid   Song (Bass).mid   Song (Bass 2).mid   Song (Drum).mid
```

`(Bass 2)` のような重複は、同じ楽器音の別トラックになります。

## 曲ごとの設定とグループ演奏

細かい調整やグループオプションは、すべて**設定**カードから開ける2列構成の1つのウィンドウにまとまっています。各設定には丸い **?** ボタンがあり、押すと短い説明が開きます — もう一度押すか ✕ で閉じます。スライダーには、初期値に戻す **↺** ボタンもあります。

![設定 — 再生、合奏、サウンド、ネットワーク同期（モニター音量のヘルプを表示中）](media/settings.png)

- **再生**: 移調、テンポ、ノート保持、最大ノート数（同時に鳴らせる音の数）、リストライク間隔（デフォルト 33 ms — 速い連打音も抜けません）、曲間の間隔。
- **合奏**: **合奏に同期**でグループ共通の拍（ダウンビートへのカウントイン）に再生をロックし、**合奏テンポに合わせる**で合奏のBPMに追従し、**合奏の招待を自動承諾**で承諾の手間を省けます。あらかじめゲーム内で合奏に参加するか開始しておいてください。
- **サウンド**: モニター音量、サステイン強制、MIDI楽器から音色を適用。
- **ネットワーク同期**: **ネットワーク同期モード**はノートを事前に送信するので、ノートが密集していても周囲のリスナーにはより安定した演奏が届きます。**自分のローカル音をミュート**と**キーアニメーションを表示**もこのモードで使えるようになります。**先読み**、**送信間隔**、**トーン先行**で細かく調整できます。**音色リレー回避策（実験的）**については、下の *既知の制限* を参照してください。

![設定のネットワーク同期セクション](media/network.png)

## 合奏で演奏する

合奏モードはパーティー全体の演奏を同じ拍にロックするので、複数のプレイヤーが同じ曲の異なるパートを同期して一緒に演奏できます。全員が**同じパーティー**にいる必要があります。

1. **合奏同期をオンにする。** **設定**で、全プレイヤーが**合奏に同期**を有効にします。**合奏の招待を自動承諾**も任意でオンにすれば、招待をいちいち手動で承諾する必要がなくなります。
2. **各プレイヤーがパートを選んで再生を押す。**演奏するステムを選んで再生を押します — Maestro はすぐに再生を始めず、**「合奏の開始を待っています…」**と表示して待機します。
3. **パーティーリーダーがゲーム内で合奏を開始する。**これはゲーム本来の合奏開始操作です。
4. **全員が同期して演奏する。**待機していた全プレイヤーが、合奏の拍にロックされたダウンビートで一斉に演奏を始めます。

フルバンド編成にするには、各プレイヤーが同じ曲の**異なる**パート（ギター、ベース、ドラム、ピアノ）をキューに入れ、任意で**合奏テンポに合わせる**をオンにすると、再生が合奏のBPMに追従します。事前に**プレビュー**を使って、セット全体がどう組み合わさるか確認しておきましょう。

## MIDIファイルを準備する

Maestro は MIDI に書かれた通りに演奏するので、少し準備しておくとゲーム内の楽器でも曲が正しく響くようになります。

### エフェクト（トーンと奏法）

設定で**MIDI楽器から音色を適用**をオンにすると、Maestro は**そのステムのトラックに割り当てられた楽器（プログラム）**からギター／ベースのエフェクトを決定します。DAW でそのトラックの General MIDI楽器を設定してください:

**ギターステム**

| この GM 楽器を割り当てる | プログラム # | 再生エフェクト |
|---|:--:|---|
| Nylon / Steel / Jazz / Clean Electric Guitar | 25–28 | Clean |
| Muted Guitar | 29 | Muffled (palm-mute) |
| Overdriven Guitar | 30 | Overdrive |
| Distortion Guitar | 31 | Distortion |
| Guitar Harmonics | 32 | Harmonics |

**ベースステム**

| この GM 楽器を割り当てる | プログラム # | 再生エフェクト |
|---|:--:|---|
| Acoustic / Finger / Pick / Fretless Bass | 33–36 | Clean |
| Slap Bass 1 / 2 | 37 / 38 | Slap |
| Synth Bass 1 / 2 | 39 / 40 | Overdrive |

- プログラム番号は DAW が表示する**1〜128**の値です。わからない場合は**楽器名**で照合してください。
- 読み取られるのはステムの**メイン楽器**のみなので、ステムごとに楽器は1つにしてください。トラック途中のプログラムチェンジは、それ以降のエフェクトを切り替えます。
- エフェクトが適用されるのは**ギターとベースのみ**です — ピアノとドラムには適用されません。
- エフェクトは実際に召喚している楽器に合わせて調整されます。**ベースにはディストーションがなく**、代わりにOverdrive として再生されます。召喚した楽器が対応していない奏法は通常再生にフォールバックします。
- **Overdrive / Distortion はネットワーク同期ではローカルのみ**です（下記の *既知の制限* を参照）。Muffled、Harmonics、Slap は全員に聞こえます。

### ドラム

ゲームのドラムキットは下記のキーに固定された**9ピースキット**で、Maestro は書かれたノートをそのまま演奏します — General MIDI のドラムを自動変換することは**ありません**ので、ドラムステムは次のキーを使う必要があります:

| MIDIノート | パーツ |
|:--:|---|
| 62 (D4) | クローズハイハット |
| 65 (F4) | キック |
| 69 (A4) | フロアタム |
| 72 (C5) | スネア |
| 74 (D5) | ミッドタム |
| 76 (E5) | ハイタム |
| 77 (F5) | ライド |
| 79 (G5) | オープンハイハット |
| 81 (A5) | クラッシュ |

これ以外のキーのノートは無音になります。標準的な General MIDI ドラムトラックから始める場合は、通常のGMノートをこれらのキーに再マッピングしてください — キック（GM 35/36）→ **F4**、スネア（38/40）→ **C5**、クローズハイハット（42）→ **D4**、オープンハイハット（46）→ **G5**、ライド（51）→ **F5**、クラッシュ（49）→ **A5**、タム → **A4 / D5 / E5**。

### その他のヒント

- **1つの音高につき1ノート:**各楽器は音高ごとに1ボイスしか鳴らせないため、同じ音高が重なる2つのノートは1つとして扱われます — ユニゾンの重ね打ちは避けてください。
- **音域に注意:**楽器の演奏可能音域外のノートは無音になります。パートを音域内に収めるには**移調**（設定）を使ってください。
- **音量は再現されません:**すべてのノートは一定の音量で再生されるため、ベロシティやダイナミクスは反映されません。
- MIDI の**タイプ 0 または 1**のファイルに対応しています。

## 既知の制限

**Overdrive / Distortion は他のプレイヤーに届きません — これはゲーム側のバグであり、Maestro 側では修正できません。**ゲームはギター／ベースの overdrive/distortion の *トーン* を自分のクライアントでしかレンダリングせず、周囲のプレイヤーには送信しません。そのため**ネットワーク同期がオン**のときは他の全員に Clean で聞こえ、ネットワーク同期が**オフ**の場合でも、ディストーションが聞こえるのは *あなただけ* です — どちらのモードでも他のプレイヤーにあなたの overdrive/distortion が聞こえることはありません。設定の**音色リレー回避策（実験的）**を使うと音色を別の経路で送れますが、それが聞こえるのは同じく Stellar を使っているリスナーだけで、それ以外のプレイヤーにはゲーム側で修正されるまで Clean で聞こえます。*奏法*（Muffled、Harmonics、Slap）はこの影響を受けず、全員に聞こえます。ディストーションが重要な曲では、ネットワーク同期を**オフ**にして、少なくとも自分には正しく聞こえるようにしてください。
