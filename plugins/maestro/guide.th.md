# Maestro

ปลั๊กอินเล่น MIDI อัตโนมัติสำหรับเครื่องดนตรีวงดนตรี (นักดนตรี) ซีซัน 3 ของ Star Resonance วางไฟล์ `.mid` ของคุณไว้ในโฟลเดอร์ เลือกเพลง แล้ว Maestro จะเล่นให้คุณผ่านเครื่องดนตรีที่เรียกออกมา — เล่นคนเดียวหรือเป็นกลุ่มก็ได้ — พร้อมเพลย์ลิสต์ การซิงก์กลุ่ม และพรีวิวเสียงในเครื่อง

![กำลังแสดงดนตรีในโลกเกมโดยเปิดหน้าต่าง Maestro ไว้](media/maestro-in-world.png)

## เริ่มต้นใช้งาน

1. ติดตั้งปลั๊กอินแล้วเปิดเกมแบบ**ใช้ม็อด**
2. เปิด**Maestro**จาก Stellar launcher (กลุ่ม ปลั๊กอิน) เครื่องมือวงดนตรีใช้ได้เฉพาะในโลกเกมเท่านั้น
3. วางไฟล์ `.mid` / `.midi` ของคุณไว้ในโฟลเดอร์ `midi\` ของเกม — Maestro จะสร้างโฟลเดอร์นี้ให้เอง ใน**คลังเพลง** ปุ่ม**เปิดโฟลเดอร์**จะพาไปที่โฟลเดอร์นั้นทันที และปุ่ม**สแกนใหม่**จะโหลดไฟล์ที่คุณเพิ่งใส่เข้าไป
4. เรียกเครื่องดนตรีโหมดเล่นอิสระในเกม กด **+ เพิ่ม** เพื่อเลือกเพลงจากคลังเพลง แล้วกด**เล่น**

## Maestro Link — เล่นเป็นวงผ่านเว็บไซต์

Maestro Link ช่วยให้ทั้งวงเล่นด้วยกันได้โดยไม่ต้องใช้ระบบวงดนตรีในเกม หัวหน้าวงจะเปิดห้องบนเว็บไซต์ [maestro.stellarresonance.app](https://maestro.stellarresonance.app) เลือกเพลง และกำหนดว่าใครเล่นพาร์ตไหน — จากนั้นตัวละครของผู้เล่นแต่ละคนจะถือเครื่องดนตรีและเล่นพาร์ตของตัวเองโดยอัตโนมัติ พร้อมกันกับทุกคนในวง

![กำลังเล่นเพลงผ่าน Maestro Link ด้วยเปียโนในโลกเกม](media/link-in-world.png)

### เข้าร่วมห้อง

1. เตรียม**รหัสห้อง 6 ตัวอักษร** — สร้างห้องบนเว็บไซต์ หรือขอรหัสจากหัวหน้าวง
2. ในเกม เปิด **Maestro** → **Maestro Link**
3. พิมพ์รหัสลงในช่อง แล้วกด**เข้าร่วม**
4. เท่านี้ก็เรียบร้อย — เมื่อห้องเปิดเพลง ตัวละครของคุณจะเล่นพาร์ตของตัวเองโดยอัตโนมัติ

แผง**วิธีใช้งาน**สรุปขั้นตอนเหล่านี้ไว้ให้ และปุ่ม**เปิดเว็บไซต์**จะเปิดเว็บ Maestro Link

![Maestro Link — ใส่รหัสห้องแล้วกดเข้าร่วม](media/link-join.png)

### ระหว่างอยู่ในห้อง

![Maestro Link ระหว่างอยู่ในห้อง — ข้อมูลห้อง เพลงที่กำลังเล่น และรายชื่อผู้เล่น](media/link-connected.png)

- **ห้อง** แสดงรหัสและชื่อห้อง ปิงของคุณ และพาร์ตที่คุณเล่น
- **กำลังเล่น** แสดงเพลงปัจจุบัน ความคืบหน้า และเพลง**ถัดไป**
- **ผู้เล่น** แสดงทุกคนในห้อง พร้อมชื่อ เครื่องดนตรี สถานะ และปิง สถานะจะเป็น**เล่นอยู่** **พร้อม** **ว่าง** หรือ**ปัญหา** โดย*ปัญหา*จะขึ้นเฉพาะเมื่อพาร์ตที่กำลังเล่นอยู่ตอนนี้เล่นไม่ได้เท่านั้น — การที่ยังไม่มีเครื่องดนตรีไม่ถือเป็นปัญหา เพราะ Link จะถือเครื่องดนตรีให้เองในเพลงถัดไป กด**ซ่อน**เพื่อพับรายชื่อ
- **หยุดพาร์ตของฉัน** (สีส้ม) จะพักพาร์ตของคุณไว้ขณะที่วงยังเล่นต่อ จากนั้นปุ่มจะเปลี่ยนเป็น**เล่นพาร์ตของฉันต่อ**
- **ตัดการเชื่อมต่อ** (สีแดง) เพื่อออกจากห้อง การล็อกเอาต์จะตัดการเชื่อมต่อให้อัตโนมัติ

### เว็บไซต์

หน้าห้องบนเว็บไซต์คือที่ที่ใช้คุมวง: มีรายชื่อทุกคนที่เข้าร่วม แสดง **Now playing** (หยุดชั่วคราว หยุด ข้าม เล่นซ้ำ) และมีคิวเพลงที่ให้คุณเลือกว่าใครเล่นพาร์ตไหน พาร์ตเดียวสามารถให้ผู้เล่นหลายคนเล่นได้ และผู้เล่นคนเดียวก็รับได้หลายพาร์ตของเครื่องดนตรีเดียวกัน **Room settings** (การตั้งค่าห้อง) จะใช้กับผู้เล่นทุกคนพร้อมกัน และคุณยังปรับผู้เล่นแต่ละคนแยกได้

![เว็บไซต์ Maestro Link — ผู้เล่น Now playing และคิวเพลง](media/web-room.png)

## เล่นเพลง

หน้าต่างหลักคือเครื่องเล่นของคุณ ด้านบนคือ**กำลังเล่น** ซึ่งแสดงเพลงปัจจุบันและความคืบหน้า พร้อมปุ่ม ◀◀ / **เล่น** (**พัก**) / ▶▶ / **หยุด** และบรรทัด**ถัดไป:** ที่บอกว่าเพลงไหนจะเล่นต่อ

![หน้าต่างหลัก — กำลังเล่น คิว และการ์ดทั้งสี่ใบ](media/auto-player.png)

**คิว**

- เลือกเพลย์ลิสต์จากดรอปดาวน์ หรือใช้ **+ ใหม่** **เปลี่ยนชื่อ** และ **✕** (ลบเพลย์ลิสต์)
- **ลากเพลง**ขึ้นลงเพื่อจัดลำดับ และกด **✕** ที่แถวเพื่อนำเพลงออก
- การสลับไปเพลย์ลิสต์อื่นจะไม่หยุดเพลงที่กำลังเล่น — เพลงจะเล่นต่อไปจนกว่าคุณจะเลือกเพลงในเพลย์ลิสต์อื่นแล้วกด**เล่น**
- ไอคอนใต้คิวใช้เปิดปิด**เล่นเพลงถัดไปอัตโนมัติ** **วนซ้ำ** (ปิด / ทุกเพลง / เพลงเดียว) และ**สุ่ม** เมื่อวางเมาส์บนไอคอน ชื่อและค่าที่ตั้งไว้จะแสดงที่หัวข้อ**คิว**
- **สุ่ม** จะเล่นทุกเพลงในเพลย์ลิสต์ครั้งละหนึ่งรอบแบบสุ่มลำดับ ถ้าวนซ้ำปิดอยู่จะหยุดหลังเพลงสุดท้าย ถ้าวนซ้ำทุกเพลงจะสุ่มลำดับใหม่ทุกรอบ บรรทัด**ถัดไป:** จะแสดงเพลงที่จะเล่นต่อจริง ๆ เสมอ
- **+ เพิ่ม** จะเปิดคลังเพลง

การ์ดสี่ใบด้านล่างใช้เปิดหน้าต่างอื่น ๆ ได้แก่ **คลังเพลง** **Maestro Link** **ฟังตัวอย่าง** และ**การตั้งค่า** แต่ละใบจะแสดงสถานะสั้น ๆ เช่น จำนวนเพลง หรือคุณอยู่ในห้องหรือไม่

## ค้นหาเพลง

![คลังเพลง — ค้นหาเพลงแล้วคลิกเพื่อเพิ่มลงเพลย์ลิสต์](media/library.png)

- **ค้นหา**ตามชื่อ (✕ ล้างคำค้น) กด**สแกนใหม่**เพื่อโหลดไฟล์ใหม่ และกด**เปิดโฟลเดอร์**เพื่อไปยังโฟลเดอร์ MIDI ของคุณ
- **คลิกเพลง**เพื่อเพิ่มลงในเพลย์ลิสต์ปัจจุบัน แถวนั้นจะกะพริบเป็นสีเขียวพร้อมคำว่า**เพิ่มแล้ว** และบรรทัดด้านล่างจะยืนยันให้ เช่น *✓ เพิ่ม “Bad Apple (Piano)” ลงใน Playlist 1 · 11 เพลง*
- การเล่นจะเล่นทีละเครื่องดนตรีเท่านั้น ดังนั้นให้เพิ่มเฉพาะสเต็มที่คุณต้องการเล่น

## พรีวิวก่อนเล่น

ทดลองฟังเพลงผ่าน**เสียงเครื่องดนตรีจริงในเกม**ได้โดยไม่ต้องเรียกเครื่องดนตรีออกมา — พรีวิวจะเล่นให้คุณฟังคนเดียว คนรอบข้างจะไม่ได้ยิน

![ฟังตัวอย่าง — เพลงที่กำลังฟัง ตัวเลือกซิงก์กับวง และแถวของแต่ละสเต็ม](media/preview.png)

- ส่วน**ฟังตัวอย่าง**แสดงเพลงที่เลือกในคิวพร้อมความคืบหน้า และปุ่ม**พรีวิว**กับ**หยุด**
- **ซิงก์กับวง**: **ซิงก์เครื่องดนตรี**จะรอให้การเล่นวงของคุณเริ่มก่อน แล้วเล่นตามไปด้วยกัน — ให้ปิดเสียงพาร์ตที่คุณเล่นเอง **ออฟเซ็ตซิงก์**จะหน่วงพรีวิวให้ตรงกับเสียงที่วงได้ยิน และปุ่ม **= ดีเลย์ของวง** จะตั้งค่านี้ให้อัตโนมัติ
- **สเต็ม**มีหนึ่งแถวต่อหนึ่งไฟล์ แต่ละแถวมีสวิตช์ปิดเสียง เครื่องดนตรี โหมด**ซัสเทน** และสวิตช์**โทน** ทำให้คุณได้ยินว่าเพลงจะออกมาเป็นอย่างไรอย่างแม่นยำ

การตั้งชื่อแบบหลายสเต็มสำคัญมากในพรีวิว: ตั้งชื่อพาร์ตต่าง ๆ ของเพลงเดียวกันด้วยชื่อหลักเดียวกัน แล้วปิดท้ายด้วยชื่อเครื่องดนตรีในวงเล็บ เมื่อคุณเลือกไฟล์ใดไฟล์หนึ่ง พรีวิวจะโหลด**ทั้งชุด**ให้

```
Song (Piano).mid   Song (Guitar).mid   Song (Bass).mid   Song (Bass 2).mid   Song (Drum).mid
```

ไฟล์ที่ซ้ำกันอย่าง `(Bass 2)` จะกลายเป็นแทร็กแยกของตัวเองที่ใช้เสียงเครื่องดนตรีเดียวกัน

## การตั้งค่าต่อเพลง & การเล่นเป็นกลุ่ม

การปรับละเอียดและตัวเลือกการเล่นเป็นกลุ่มทั้งหมดอยู่ในหน้าต่างเดียวแบบสองคอลัมน์ ซึ่งเปิดได้จากการ์ด**การตั้งค่า** ทุกการตั้งค่ามีปุ่มกลม **?** ที่เปิดคำอธิบายสั้น ๆ — กดอีกครั้งหรือกด ✕ เพื่อปิด และสไลเดอร์ทุกอันมีปุ่ม **↺** สำหรับคืนค่าเริ่มต้น

![การตั้งค่า — การเล่น วงดนตรี เสียง และซิงก์เครือข่าย โดยเปิดคำอธิบายของระดับเสียงมอนิเตอร์ไว้](media/settings.png)

- **การเล่น**: เปลี่ยนระดับเสียง เทมโป ค้างโน้ต โน้ตสูงสุด (จำนวนโน้ตที่ดังพร้อมกันได้) ช่วงตีซ้ำ (ค่าเริ่มต้น 33 ms เพื่อไม่ให้โน้ตซ้ำเร็ว ๆ หายไป) และช่วงเว้นระหว่างเพลง
- **วงดนตรี**: **ซิงก์กับวงดนตรี**จะล็อกการเล่นไว้กับจังหวะร่วมของกลุ่ม (นับเข้าจนถึงจังหวะแรก) **จับจังหวะให้ตรงวงดนตรี**จะตาม BPM ของวง และ**รับคำเชิญวงดนตรีอัตโนมัติ**จะกดรับให้คุณเอง ให้เข้าร่วมหรือเริ่มวงดนตรีในเกมก่อน
- **เสียง**: ระดับเสียงมอนิเตอร์ บังคับซัสเทน และใช้โทนจากเครื่องดนตรี MIDI
- **ซิงก์เครือข่าย**: **โหมดซิงก์เครือข่าย**จะส่งโน้ตของคุณล่วงหน้า ทำให้ผู้ฟังรอบข้างได้ยินการเล่นที่นิ่งขึ้นแม้โน้ตจะหนาแน่น และยังเปิดให้ใช้**ปิดเสียงในเครื่องของฉัน**กับ**แสดงแอนิเมชันคีย์** ปรับละเอียดได้ด้วย**มองล่วงหน้า** **ส่งทุก** และ**นำโทนเสียงล่วงหน้า** ส่วน**วิธีแก้การส่งโทน (ทดลอง)** อธิบายไว้ใน*ข้อจำกัดที่ทราบ*ด้านล่าง

![ส่วนซิงก์เครือข่ายในการตั้งค่า](media/network.png)

## เล่นในวงดนตรี

โหมดวงดนตรีล็อกการแสดงของทั้งปาร์ตี้ให้ตรงจังหวะเดียวกัน ทำให้ผู้เล่นหลายคนเล่นพาร์ตต่างกันของเพลงเดียวกันพร้อมกันแบบซิงก์ได้ ทุกคนต้อง**อยู่ปาร์ตี้เดียวกัน**

1. **เปิดซิงก์วงดนตรี** ใน**การตั้งค่า** เปิดใช้**ซิงก์กับวงดนตรี** — ในผู้เล่นทุกคน การเปิด**รับคำเชิญวงดนตรีอัตโนมัติ**ด้วยก็เป็นทางเลือก เพื่อไม่ต้องรับคำเชิญเองทีละคน
2. **ผู้เล่นแต่ละคนเลือกพาร์ตแล้วกดเล่น** เลือกสเต็มที่จะเล่นแล้วกดเล่น — Maestro จะไม่เริ่มทันทีแต่จะค้างไว้และแสดง**"กำลังรอวงเริ่มเล่น…"**
3. **หัวหน้าปาร์ตี้เริ่มวงดนตรีในเกม** นี่คือการเริ่มวงดนตรีของเกมเอง
4. **ทุกคนเล่นพร้อมกันแบบซิงก์** ผู้เล่นที่รออยู่ทั้งหมดจะเริ่มพร้อมกันที่ดาวน์บีต ล็อกกับจังหวะของวงดนตรี

สำหรับวงเต็มรูปแบบ ให้ผู้เล่นแต่ละคนเพิ่มพาร์ต**ที่ต่างกัน** (กีตาร์ เบส กลอง เปียโน) ของเพลงเดียวกันเข้าคิวและเปิด**จับจังหวะให้ตรงวงดนตรี**ตามต้องการ เพื่อให้การเล่นตามค่า BPM ของวง ใช้**ฟังตัวอย่าง**ล่วงหน้าเพื่อฟังว่าทั้งชุดเข้ากันอย่างไร

## เตรียมไฟล์ MIDI ของคุณ

Maestro เล่นตาม MIDI ที่เขียนไว้ตรง ๆ ดังนั้นการเตรียมเพลงเล็กน้อยจะช่วยให้เสียงออกมาถูกต้องบนเครื่องดนตรีในเกม

### เอฟเฟกต์ (โทนและเทคนิค)

เปิด**ใช้โทนจากเครื่องดนตรี MIDI**ในการตั้งค่า แล้ว Maestro จะเลือกเอฟเฟกต์กีตาร์/เบสจาก**เครื่องดนตรี (โปรแกรม) ที่กำหนดให้แทร็กของสเต็มนั้น** ตั้งค่าเครื่องดนตรี General MIDI ของแทร็กนั้นใน DAW ของคุณ:

**สเต็มกีตาร์**

| กำหนดเครื่องดนตรี GM นี้ | หมายเลขโปรแกรม | เล่นเป็น |
|---|:--:|---|
| Nylon / Steel / Jazz / Clean Electric Guitar | 25–28 | Clean |
| Muted Guitar | 29 | Muffled (palm-mute) |
| Overdriven Guitar | 30 | Overdrive |
| Distortion Guitar | 31 | Distortion |
| Guitar Harmonics | 32 | Harmonics |

**สเต็มเบส**

| กำหนดเครื่องดนตรี GM นี้ | หมายเลขโปรแกรม | เล่นเป็น |
|---|:--:|---|
| Acoustic / Finger / Pick / Fretless Bass | 33–36 | Clean |
| Slap Bass 1 / 2 | 37 / 38 | Slap |
| Synth Bass 1 / 2 | 39 / 40 | Overdrive |

- หมายเลขโปรแกรมคือค่า**1–128**ที่ DAW ของคุณแสดง หากไม่แน่ใจให้จับคู่ด้วย**ชื่อเครื่องดนตรี**
- จะอ่านเฉพาะ**เครื่องดนตรีหลัก**ของสเต็มเท่านั้น จึงควรให้แต่ละสเต็มมีเครื่องดนตรีเดียว การเปลี่ยนโปรแกรมกลางแทร็กจะเปลี่ยนเอฟเฟกต์ตั้งแต่จุดนั้นเป็นต้นไป
- เอฟเฟกต์ใช้ได้กับ**กีตาร์และเบสเท่านั้น** — เปียโนและกลองจะไม่มีผล
- เอฟเฟกต์จะถูกจำกัดตามเครื่องดนตรีที่คุณเรียกออกมาจริง **เบสไม่มีดิสทอร์ชัน** — จะเล่นเป็น Overdrive แทนและเทคนิคใดที่เครื่องดนตรีที่เรียกออกมาทำไม่ได้จะกลับไปเล่นแบบปกติ
- **Overdrive / Distortion เป็นแบบในเครื่องเท่านั้นเมื่อใช้ซิงก์เครือข่าย** (ดู *ข้อจำกัดที่ทราบ* ด้านล่าง) Muffled, Harmonics และ Slap จะได้ยินโดยทุกคน

### กลอง

ชุดกลองของเกมเป็น**ชุด 9 ชิ้น**ที่ตายตัวตามคีย์ด้านล่าง และ Maestro จะเล่นโน้ตของคุณตามที่เขียนไว้ตรง ๆ — จะ**ไม่**แปลงกลอง General MIDI ให้อัตโนมัติ — ดังนั้นสเต็มกลองต้องใช้คีย์เหล่านี้:

| โน้ต MIDI | ชิ้นส่วน |
|:--:|---|
| 62 (D4) | ไฮแฮตปิด |
| 65 (F4) | กระเดื่อง |
| 69 (A4) | ฟลอร์ทอม |
| 72 (C5) | สแนร์ |
| 74 (D5) | มิดทอม |
| 76 (E5) | ไฮทอม |
| 77 (F5) | ไรด์ |
| 79 (G5) | ไฮแฮตเปิด |
| 81 (A5) | แคร็ช |

โน้ตที่อยู่นอกคีย์เหล่านี้จะไม่มีเสียง หากเริ่มจากแทร็กกลอง General MIDI มาตรฐาน ให้แมปโน้ต GM ปกติใหม่ไปยังคีย์เหล่านี้ — กระเดื่อง (GM 35/36) → **F4**, สแนร์ (38/40) → **C5**, ไฮแฮตปิด (42) → **D4**, ไฮแฮตเปิด (46) → **G5**, ไรด์ (51) → **F5**, แคร็ช (49) → **A5**, ทอม → **A4 / D5 / E5**

### เคล็ดลับเพิ่มเติม

- **หนึ่งโน้ตต่อหนึ่งระดับเสียง:** แต่ละเครื่องดนตรีเล่นได้หนึ่งเสียงต่อระดับเสียงหนึ่ง ดังนั้นโน้ตที่ซ้อนทับกันเหมือนกันสองตัวจะนับเป็นหนึ่ง — หลีกเลี่ยงการซ้อนยูนิซันหลายชั้น
- **ระวังช่วงเสียง:** โน้ตที่อยู่นอกช่วงเสียงที่เครื่องดนตรีเล่นได้จะไม่มีเสียง ใช้**เปลี่ยนระดับเสียง** (ตั้งค่า) เพื่อนำพาร์ตเข้าสู่ช่วงเสียงที่เล่นได้
- **ไม่สะท้อนระดับความดัง:** ทุกโน้ตจะเล่นด้วยความดังคงที่ ดังนั้น velocity และไดนามิกจะไม่ถูกถ่ายทอดมา
- รองรับไฟล์ MIDI **ประเภท 0 หรือ 1**

## ข้อจำกัดที่ทราบ

**Overdrive / Distortion ไม่ไปถึงผู้เล่นคนอื่น — นี่คือบั๊กของเกม ไม่ใช่สิ่งที่ Maestro แก้ไขได้** เกมเรนเดอร์ *โทน* overdrive/distortion ของกีตาร์/เบสบนไคลเอนต์ของคุณเองเท่านั้น และไม่ส่งต่อให้คนรอบข้างเลย ดังนั้นเมื่อ**ซิงก์เครือข่ายเปิดอยู่** คนอื่นทุกคนจะได้ยินเป็น Clean และแม้ซิงก์เครือข่าย**ปิด**อยู่ ก็มีเพียง *คุณ*เท่านั้นที่ได้ยินดิสทอร์ชัน — ผู้เล่นคนอื่นจะไม่ได้ยิน overdrive/distortion ของคุณในโหมดใดเลย **วิธีแก้การส่งโทน (ทดลอง)** ในการตั้งค่าจะส่งโทนของคุณผ่านอีกเส้นทางหนึ่ง แต่จะได้ยินเฉพาะผู้ฟังที่ใช้ Stellar ด้วยเท่านั้น ส่วนคนอื่นยังคงได้ยินเป็น Clean จนกว่าเกมจะแก้ไข *เทคนิค* (Muffled, Harmonics, Slap) ไม่ได้รับผลกระทบและทุกคนได้ยิน สำหรับเพลงที่ดิสทอร์ชันสำคัญ ให้เล่นโดย**ปิด**ซิงก์เครือข่ายเพื่อให้อย่างน้อยเสียงออกมาถูกต้องสำหรับคุณเอง
