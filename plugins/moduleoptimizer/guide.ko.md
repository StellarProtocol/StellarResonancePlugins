# 모듈 최적화

설정한 목표에 가장 알맞은 모듈 조합을 찾아주고, 게임 자체의 장착 흐름을 통해 직접 적용까지 해
줍니다.

![Module optimizer](media/module-optimizer.png)

## 사용 방법

1. 플러그인을 설치하고 **모드 적용** 상태로 게임을 실행하세요.
2. Stellar 오버레이에서 최적화 도구를 열고 **목표 능력치** — 원하는 능력치와 최소값(예:
   *Life Wave ≥ 20*)을 설정합니다.
3. 최적화를 실행하세요: 인벤토리의 모듈 조합(게임 패치 3.7 기준 모듈 슬롯 5개)을 나열하고
   점수를 매겨 가장 좋은 후보들을 보여줍니다.

![Results](media/moduleoptimizer-results.png)
4. 제안된 구성을 검토하고 **적용**하세요. 계획은 사용자가 승인하며, 플러그인은 게임 자체의
   장착 흐름을 통해 장착하므로 게임의 검사를 우회하지 않습니다.

## 팁

- 적용은 검증됩니다: 계획을 실행한 뒤 장착된 세트를 다시 확인하고, 서버가 무시한 장착이 있으면
  한 번 재시도합니다; 계속 실패하면 멈춘 슬롯의 이름을 알려줍니다.
- 능력치 최소값은 하한선을 인식합니다 — 희소한 능력치가 풍부한 공동 목표에 밀려 풀에서 밀려나지
  않습니다.
