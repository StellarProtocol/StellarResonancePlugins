# Optimizer Modul

Menemukan kombinasi modul terbaik untuk target yang kamu tetapkan — dan bisa menerapkannya untukmu,
melalui alur pemasangan bawaan game itu sendiri.

![Module optimizer](media/module-optimizer.png)

## Cara menggunakan

1. Instal plugin lalu jalankan game dalam mode **Modded**.
2. Buka optimizer dari overlay Stellar dan atur **atribut target**-mu — atribut yang kamu inginkan
   beserta nilai minimumnya (misalnya *Life Wave ≥ 20*).
3. Jalankan optimizer: ia akan mendaftar dan menilai kombinasi modul dari inventarismu (5 slot
   modul per patch game 3.7) lalu menampilkan kandidat terbaik.

![Results](media/moduleoptimizer-results.png)
4. Tinjau setup yang disarankan lalu **terapkan**. Kamu yang menyetujui rencananya — plugin
   memasangnya melalui alur pemasangan bawaan game itu sendiri, tanpa pernah melewati
   pemeriksaannya.

## Tips

- Penerapan ini diverifikasi: setelah rencana dijalankan, set yang terpasang diperiksa ulang dan
  pemasangan mana pun yang diabaikan server akan dikirim ulang sekali; kegagalan yang terus
  berlanjut akan menyebutkan nama slot yang macet.
- Nilai minimum atribut sadar akan batas bawahnya — atribut langka tidak akan tersisih dari
  kumpulan kandidat oleh target bersama yang berlimpah.
