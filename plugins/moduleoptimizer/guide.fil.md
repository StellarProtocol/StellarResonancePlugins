# Module Optimizer

Hinahanap ang pinakamagandang kombinasyon ng module para sa mga target na itinakda mo — at
maaaring i-apply ito para sa iyo, sa pamamagitan ng sariling equip flow ng laro.

![Module optimizer](media/module-optimizer.png)

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa mode na **Modded**.
2. Buksan ang optimizer mula sa Stellar overlay at itakda ang iyong **mga target na katangian** —
   ang mga attribute na gusto mo at anumang minimum (hal. *Life Wave ≥ 20*).
3. Patakbuhin ang optimizer: binibilang at sini-score nito ang mga kombinasyon ng module mula sa
   imbentaryo mo (5 module slot simula sa game patch 3.7) at ipinapakita ang pinakamahuhusay na
   kandidato.

![Results](media/moduleoptimizer-results.png)
4. Suriin ang iminumungkahing setup at **i-apply** ito. Ikaw ang nag-aaprubar ng plano — ini-equip
   ito ng plugin sa pamamagitan ng sariling equip flow ng laro, kailanman hindi dumadaan sa mga
   check nito.

## Mga Tip

- Verified ang pag-apply: pagkatapos tumakbo ang plano, muling sinusuri ang na-equip na set at
  anumang equip na na-ignore ng server ay muling isusulong nang isang beses; ang paulit-ulit na
  pagkabigo ay nagbabanggit ng mga pangalan ng natigil na slot.
- Alam ng mga minimum ng attribute ang kanilang floor — ang isang bihirang attribute ay hindi
  matutulak palabas ng pool ng isang masaganang co-target.
