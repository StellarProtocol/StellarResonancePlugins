# ModuleOptimizer

設定した目標に最も合うモジュールの組み合わせを見つけ出し、ゲーム自身の装備フローを通じて自動で適用することもできます。

![Module optimizer](media/module-optimizer.png)

## 使い方

1. プラグインをインストールし、**Mod有効** でゲームを起動します。
2. Stellarオーバーレイからオプティマイザーを開き、**対象属性** — 欲しい属性と最小値（例: *Life Wave ≥ 20*）を設定します。
3. オプティマイザーを実行します：インベントリ内のモジュールの組み合わせ（ゲームパッチ3.7時点でモジュールスロット5つ）を列挙してスコアを付け、最良の候補を表示します。

![Results](media/moduleoptimizer-results.png)
4. 提案されたセットアップを確認し、**適用** します。プランは自分で承認する必要があり、プラグインはゲーム自身の装備フローを通じて装備するため、ゲームのチェックを回避することはありません。

## ヒント

- 適用は検証されます：プラン実行後に装備されたセットが再チェックされ、サーバーが無視した装備があれば一度だけ再送されます；失敗が続く場合は詰まったスロットの名前が表示されます。
- 属性の最小値はフロア（下限）を認識します — 希少な属性が、豊富な共同目標によってプールから押し出されることはありません。
