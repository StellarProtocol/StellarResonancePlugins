# ChatTools

Pagkuha ng chat kasama ng mga kapaki-pakinabang na chat tool, sa isang window na puwede mong iwanang bukas kahit saan.

![ChatTools window](media/chattools.png)

## Paano gamitin

1. I-install ang plugin at i-launch ang laro nang **May mod**.
2. Buksan ang ChatTools window mula sa Stellar overlay. Kinukuha nito ang chat ng laro bilang isang log na may
   kulay — magkaiba ang kulay ng Sabihin, Mundo, Party, bulong, at mga mensahe ng sistema.
3. Mag-type sa composer sa ibaba at pumili ng channel button (Sabihin / Mundo / Party / Guild) para magpadala
   nang hindi hinihipo ang sariling chat box ng laro.

## Awtomatikong sagot sa mga bulong

I-on ang **Awtomatikong sagot sa mga bulong** at itakda ang iyong sagot — habang wala ka (nangingisda, gumagawa
ng item, o AFK), ang mga papasok na bulong ay awtomatikong masasagot, na may cooldown kada nagpadala para walang
ma-spam.
