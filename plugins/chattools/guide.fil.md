# ChatTools

Ang chat ng laro sa isang window na puwede mong ilipat, i-resize at iwanang bukas kahit saan, may mga channel tab, sticker, bulong at pagsasalin.

![ChatTools window](media/chattools.png)

## Pagsisimula

1. I-install ang plugin at i-launch ang laro nang **May mod** (kailangan ng Stellar 2.27.1 o mas bago).
2. Pindutin ang **F12** o buksan ang ChatTools mula sa Stellar menu.
3. I-drag ang title bar para ilipat ang window, at ang kanang-ibabang sulok para i-resize ito.

## Mga channel tab

May sariling tab ang Lahat, Mundo, Kasalukuyan, Party, Guild, Bulong at Sistema, at may tuldok kapag may hindi pa nababasang mensahe. Mag-scroll pataas para basahin ang mga lumang mensahe; ibabalik ka ng "bagong mensahe" bar sa pinakabago. I-click ang avatar ng player para buksan ang name card niya, o i-right-click ang mensahe para kopyahin ito.

## Pagpapadala ng mensahe

Mag-type sa box sa ibaba at pindutin ang **Enter** o **Ipadala**. Ang button sa kaliwa ang pumipili ng channel.

![Pagpili ng channel na padadalhan](media/chattools-send-to.png)

## Mga sticker at emoji

I-click ang ☺ para buksan ang picker. I-click ang sticker para ipadala ito agad, o ang emoji para idagdag ito kung nasaan ang cursor mo. I-right-click ang sticker para idagdag ito sa ★ tab ng mga paborito, at i-drag ang mga paborito para ayusin ang pagkakasunod-sunod.

![Emoji picker](media/chattools-emoji.png)

![Mga paboritong sticker](media/chattools-stickers.png)

## Mabilisang parirala

I-click ang ＋ para buksan ang mga mabilisang parirala mo. I-click ang isa para ipadala ito. Para mag-save ng bago, i-type ito sa "Bagong parirala…" at i-click ang **Idagdag**. I-drag para ayusin ang pagkakasunod-sunod, o itapat ang cursor at i-click ang ✕ para burahin (hanggang 30).

![Mabilisang parirala](media/chattools-quick-phrases.png)

## Mga bulong

Sa Bulong tab, isang usapan para sa bawat tao, may tuldok kung online at bilang ng hindi pa nababasa. I-click ang **+ Bagong chat** para bumulong sa isang tao mula sa friends list mo.

![Usapan sa bulong](media/chattools-whisper.png)

## Pagsasalin

**Mensahe ng ibang tao:** itapat ang cursor sa mensahe at i-click ang 文A para isalin ito sa wika mo (piliin ito sa Mga Setting → Isalin sa).

![Isinaling mensahe](media/chattools-translate-in.png)

**Mensahe mo:** i-type ito, i-click ang 文A sa tabi ng chat box at pumili ng wika. I-click ang **I-undo** para maibalik ang orihinal mong text.

![Pagsasalin ng sarili mong mensahe](media/chattools-translate-out.png)

Ipinapadala lang ang text sa Google Translate kapag nag-click ka.

## Compact na mode

I-on ang **Compact na mode** sa Mga Setting para isang linya lang bawat mensahe, walang bubble o avatar.

![Compact na mode](media/chattools-compact.png)

## Mga Setting

I-click ang gear sa title bar.

- **Awtomatikong sagot sa mga bulong:** i-on ito at isulat ang sagot mo. Habang wala ka, matatanggap ito ng bawat taong bumulong sa iyo, hindi hihigit sa isang beses kada 30 segundo.
- **Tab na Lahat:** piliin kung aling mga channel ang ipapakita sa tab na Lahat. I-click ang channel para i-off ito; laging lumalabas ang sarili mong mga mensahe.
- **Pagsasalin:** ang wika mo, at kung lalabas ang button na isalin kapag itinapat ang cursor.
- **Whisper history:** i-save ang mga bulong sa PC na ito (ang pinakabagong 500 bawat usapan, hiwalay para sa bawat character), o burahin ang mga ito.
- **Compact na mode:** isang linya bawat mensahe, walang bubble o avatar.

![Mga Setting](media/chattools-settings.png)

Sumusunod ang mga kulay ng channel sa mga chat tab; palitan ang mga ito sa mga setting ng Theme ng Stellar.

## Mga hotkey

Palitan ang mga ito sa mga setting ng hotkey ng Stellar.

- **I-toggle ang bintana ng ChatTools:** F12.
- **I-focus/alisin ang focus sa input ng chat:** Enter. Pindutin nang isang beses para mag-type, at isa pa para bumalik sa laro. Habang bukas lang ang ChatTools.
- **Susunod / Nakaraang tab ng chat:** walang key hangga't hindi ka pumipili. Habang bukas lang ang ChatTools.
