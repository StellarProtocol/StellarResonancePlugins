# 채팅 도구

게임 채팅을 옮기고, 크기를 조절하고, 어디서든 열어둘 수 있는 창으로 사용하세요. 채널 탭, 스티커, 귓속말, 번역을 지원합니다.

![채팅 도구 창](media/chattools.png)

## 시작하기

1. 플러그인을 설치하고 게임을 **모드 적용**으로 실행하세요(Stellar 2.27.1 이상 필요).
2. **F12**를 누르거나 Stellar 메뉴에서 채팅 도구를 엽니다.
3. 제목 표시줄을 드래그해 창을 옮기고, 오른쪽 아래 모서리를 드래그해 크기를 조절합니다.

## 채널 탭

전체, 월드, 주변, 파티, 길드, 귓속말, 시스템마다 탭이 있으며, 읽지 않은 메시지가 있으면 점이 표시됩니다. 위로 스크롤하면 이전 메시지를 볼 수 있고, "새 메시지" 바를 누르면 최신 메시지로 돌아갑니다. 플레이어 아바타를 클릭하면 명함이 열리고, 메시지를 우클릭하면 복사할 수 있습니다.

## 메시지 보내기

아래쪽 입력창에 입력하고 **Enter**를 누르거나 **보내기**를 클릭합니다. 왼쪽 버튼으로 채널을 선택합니다.

![보낼 채널 선택](media/chattools-send-to.png)

## 스티커와 이모지

☺를 클릭하면 선택창이 열립니다. 스티커를 클릭하면 바로 보내지고, 이모지를 클릭하면 커서 위치에 입력됩니다. 스티커를 우클릭하면 ★ 즐겨찾기 탭에 추가되며, 즐겨찾기는 드래그해서 순서를 바꿀 수 있습니다.

![이모지 선택창](media/chattools-emoji.png)

![즐겨찾기 스티커](media/chattools-stickers.png)

## 상용구

＋를 클릭하면 상용구가 열립니다. 상용구를 클릭하면 바로 보내집니다. 새로 저장하려면 "새 상용구…"에 입력하고 **추가**를 클릭하세요. 드래그해서 순서를 바꾸거나, 마우스를 올리고 ✕를 클릭해 삭제할 수 있습니다(최대 30개).

![상용구](media/chattools-quick-phrases.png)

## 귓속말

귓속말 탭은 상대별로 대화를 하나씩 보관하며, 온라인 표시 점과 읽지 않은 메시지 수를 보여줍니다. **+ 새 채팅**을 클릭하면 친구 목록에서 상대를 골라 귓속말할 수 있습니다.

![귓속말 대화](media/chattools-whisper.png)

## 번역

**다른 사람의 메시지:** 메시지에 마우스를 올리고 文A를 클릭하면 내 언어로 번역됩니다(언어는 설정 → 번역 언어에서 선택).

![번역된 메시지](media/chattools-translate-in.png)

**내 메시지:** 입력한 뒤 입력창 옆의 文A를 클릭하고 언어를 고릅니다. **실행 취소**를 클릭하면 원래 문장으로 돌아갑니다.

![내 메시지 번역](media/chattools-translate-out.png)

텍스트는 클릭할 때만 Google 번역로 전송됩니다.

## 간결 모드

설정에서 **간결 모드**를 켜면 말풍선과 아바타 없이 메시지를 한 줄로 표시합니다.

![간결 모드](media/chattools-compact.png)

## 설정

제목 표시줄의 톱니바퀴를 클릭합니다.

- **귓속말 자동 응답:** 켜고 응답 문구를 작성하세요. 자리를 비운 동안 귓속말을 보낸 사람에게 자동으로 응답하며, 같은 사람에게는 최대 30초에 한 번만 보냅니다.
- **번역:** 내 언어, 그리고 마우스를 올렸을 때 번역 버튼을 표시할지 여부.
- **귓속말 기록:** 귓속말을 이 PC에 보관하거나(대화마다 최신 500개, 캐릭터별로 따로) 삭제합니다.
- **간결 모드:** 말풍선과 아바타 없이 메시지를 한 줄로 표시합니다.

![설정](media/chattools-settings.png)

채널 색상은 채팅 탭과 같으며, Stellar 테마 설정에서 변경할 수 있습니다.

## 단축키

Stellar 단축키 설정에서 변경할 수 있습니다.

- **채팅 도구 창 전환:** F12.
- **채팅 입력창 포커스 전환:** Enter. 한 번 누르면 입력할 수 있고, 다시 누르면 게임으로 돌아갑니다. 채팅 도구 창이 열려 있을 때만 작동합니다.
- **다음 채팅 탭 / 이전 채팅 탭:** 직접 지정하기 전까지 키가 없습니다. 채팅 도구 창이 열려 있을 때만 작동합니다.
