# 채팅 도구

채팅 캡처에 더해, 어디서든 열어둘 수 있는 창에서 쓰는 채팅 편의 기능 모음입니다.

![채팅 도구 창](media/chattools.png)

## 사용 방법

1. 플러그인을 설치하고 게임을 **모드 적용**으로 실행하세요.
2. Stellar 오버레이에서 채팅 도구 창을 엽니다. 게임 채팅을 색상별 로그로 기록합니다 — 주변, 월드, 파티, 귓속말,
   시스템 메시지가 각각 고유한 색을 가집니다.
3. 하단의 입력창에 입력한 뒤 채널 버튼(주변 / 월드 / 파티 / 길드)을 선택하면 게임 자체의 채팅창을 건드리지 않고
   보낼 수 있습니다.

## 귓속말 자동 응답

**귓속말 자동 응답**을 켜고 응답 문구를 설정하세요 — 자리를 비운 동안(낚시, 제작, AFK) 들어오는 귓속말에 자동으로
응답하며, 보낸 사람별 쿨타임이 있어 아무도 도배되지 않습니다.
