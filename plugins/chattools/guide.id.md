# ChatTools

Penangkap chat plus berbagai alat chat quality-of-life, dalam satu jendela yang bisa kamu biarkan terbuka di mana saja.

![Jendela ChatTools](media/chattools.png)

## Cara pakai

1. Pasang plugin-nya lalu jalankan game dalam mode **Dengan mod**.
2. Buka jendela ChatTools dari overlay Stellar. Jendela ini menangkap chat game ke dalam log berwarna — Sekitar,
   Dunia, Party, bisikan, dan pesan sistem masing-masing punya warna sendiri.
3. Ketik di kolom pengetikan di bagian bawah lalu pilih tombol channel (Sekitar / Dunia / Party / Guild) untuk
   mengirim tanpa menyentuh kotak chat game itu sendiri.

## Balas otomatis untuk bisikan

Nyalakan **Balas otomatis bisikan** dan atur teks balasanmu — saat kamu sedang pergi (memancing, crafting, AFK),
bisikan yang masuk akan otomatis dibalas dengan pesanmu, dengan cooldown per pengirim supaya tidak ada yang
kebanjiran pesan.
