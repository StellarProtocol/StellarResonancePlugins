# Wardrobe

I-save ang mga kasuotang suot mo at lumipat sa pagitan ng mga ito nang instant — sa pamamagitan ng
hotkey o mula sa isang menu — na may live na 3D preview.

![The Wardrobe window](media/wardrobe-window.png)

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa mode na **May mod**.
2. Magbihis sa loob ng laro kung paano mo gusto, pagkatapos ay buksan ang **Wardrobe** mula sa
   Stellar launcher (o i-bind ang window-toggle hotkey nito) at i-click ang **I-save ang
   kasalukuyang kasuotan**. Naka-store ito sa isang pinangalanang slot para sa character na iyon.
3. Palitan ang kasuotan mo sa laro, pagkatapos ay ibalik ang isang luma:
   - Pindutin ang naka-bind na hotkey — ang unang 8 naka-save na kasuotan ay naka-map sa
     **Ilapat ang Kasuotan 1**–**Ilapat ang Kasuotan 8** (i-bind ang mga ito sa **Mga Setting ng
     Stellar → Mga Hotkey**, hindi pa naka-bind bilang default), o
   - I-click ang **play (▶)** button sa kahit anong row sa Wardrobe window.

## Mga button ng row

Ang bawat naka-save na kasuotan ay may maliit na toolbar:

- **✎ palitan ang pangalan** — bigyan ng pangalan ang kasuotan.
- **⟳ i-update** — muling kunin ang kasuotang suot mo ngayon papunta sa slot na ito (mananatili
  ang pangalan at posisyon nito).
- **▲ / ▼ ayusin muli** — ilipat pataas o pababa; ang unang 8 slot ay ang mga hotkey slot.
- **▶ i-apply** — isuot ang kasuotang ito.
- **🗑 burahin** — alisin ito.

Nagtatanong muna ng kumpirmasyon ang i-update at burahin.

## Preview

I-hover ang kahit anong row para makita ang kasuotang iyon sa live na 3D model ng character mo.
**I-drag** para umikot, **mag-scroll** para mag-zoom, at **shift-drag** para mag-pan.

## Mga Paalala

- Naka-save ang mga kasuotan **kada character**.
- Dumadaan ang paglipat sa sariling fashion system ng laro, na nag-aapply ng sarili nitong mga
  patakaran (halimbawa, hindi ka makakapalit ng kasuotan habang nasa labanan) — ipinapakita ng laro
  ang isang banner kung hindi pinapayagan ang paglipat sa ngayon.
- Available ang plugin sa English, 日本語, ไทย, Bahasa Indonesia, Filipino, at 한국어.
