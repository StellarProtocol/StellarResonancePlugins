# Wardrobe

I-save ang mga kasuotang suot mo at lumipat sa pagitan ng mga ito nang instant — sa isang click o
hotkey — na may live na 3D preview ng bawat kasuotan.

![The Wardrobe window](media/wardrobe-window.png)

## Paano gamitin

1. I-install ang plugin at buksan ang laro sa mode na **May mod**.
2. Magbihis sa loob ng laro kung paano mo gusto, pagkatapos ay buksan ang **Wardrobe** mula sa
   Stellar launcher (o i-bind ang hotkey na **Buksan ang Wardrobe**) at i-click ang **I-save ang suot**
   sa kanang itaas. Idinadagdag ang kasuotan sa listahan ng character na iyon.
3. Palitan ang kasuotan mo sa laro, pagkatapos ay ibalik ang isang naka-save:
   - I-click ang **Isuot** sa row nito, o
   - Pindutin ang hotkey nito — ang unang 8 kasuotan sa listahan ay naka-map sa
     **Ilapat ang Kasuotan 1**–**Ilapat ang Kasuotan 8** (i-bind ang mga ito sa **Stellar Settings ›
     Hotkeys**; hindi pa naka-bind bilang default).

Ang bilog na **?** sa tabi ng **I-save ang suot** ay nagpapakita ng maikling tulong. Sinasabi ng linya sa
itaas kung aling naka-save na kasuotan ang suot mo at kung ilan ang mga kasuotan mo.

## Ang listahan ng kasuotan

Ipinapakita ng bawat row, mula kaliwa pakanan:

- **Hawakan para i-drag** — i-drag ang row pataas o pababa para palitan ang puwesto nito. Ang unang 8 row
  ang mga hotkey slot.
- **Hotkey badge** — ang key na na-bind mo sa slot na iyon (halimbawa **F1**). Kung wala pang key ang
  slot, **H1**–**H8** ang ipinapakita; numero lang ang ipinapakita ng mga row pagkatapos ng ika-8.
- **Pangalan** at **bilang ng piraso** (halimbawa "12 pcs").
- **Isuot** — isuot ang kasuotang ito. **Suot** ang ipinapakita sa kasuotang suot mo ngayon; i-click ang
  **Suot** para isuot itong muli (halimbawa pagkatapos magpalit ng dye).
- **Lapis** — palitan ang pangalan ng kasuotan. Pindutin ang **Enter** o **✓** para i-save ang pangalan,
  **✕** para i-cancel.
- **Refresh** — palitan ang kasuotang ito ng suot mo ngayon. Mananatili ang pangalan at puwesto nito, at
  hihilingin muna nitong kumpirmahin mo gamit ang **Palitan**.
- **✕** — burahin ang kasuotan. Hihilingin muna nitong kumpirmahin mo gamit ang **Burahin**.

Habang bukas ang pagpapalit ng pangalan o isang kumpirmasyon, naghihintay ang ibang row hanggang matapos
mo ito.

## Preview

I-hover ang kahit anong row para makita ang kasuotang iyon sa live na 3D model ng character mo.
**I-drag** para umikot, **Shift+drag** para ilipat, at gamitin ang **mouse wheel** para mag-zoom.

Ipinapakita ng preview ang kasuotan nang eksakto kung paano ito na-save, kasama ang mga pirasong itinatago
nito. Ipinapakita o itinatago ng chip na **Armas: On / Off** ang armas mo sa model; kung may naka-save na
weapon skin ang kasuotan, ipinapakita ang armas sa skin na iyon.

## Mga nakikita at nakatagong piraso

Naaalala ng bawat kasuotan kung aling mga piraso ang itinago mo (gaya ng sombrero) at itinatago muli ang
mga ito kapag isinuot mo ito. Wala pa nito ang mga kasuotang na-save bago ang bersyon 1.5.0: isuot ang
kasuotan na nakikita o nakatago ang mga piraso ayon sa gusto mo, pagkatapos ay pindutin nang isang beses
ang **Refresh** → **Palitan** sa row nito.

## Mga Paalala

- Naka-save ang mga kasuotan **kada character**.
- Dumadaan ang paglipat sa sariling fashion system ng laro, na nag-aapply ng sarili nitong mga
  patakaran (halimbawa, hindi ka makakapalit ng kasuotan habang nasa labanan) — ipinapakita ng laro
  ang isang banner kung hindi pinapayagan ang paglipat sa ngayon.
- Available ang plugin sa English, 日本語, ไทย, Bahasa Indonesia, Filipino, at 한국어.
